# 插槽（字卡第二版）

字卡第一版只有等级（每级整发 +2%）。第二版给每张字卡开插槽：

- **插槽只决定种类**，自己不带数值。空槽没有任何加成。
- **数值全看镶进去的印章**，印章的品质越高数值越大。同一个槽换一枚更好的印章就变强，不用重刷槽。

核心新类型是「字运」：提高这个字在改装三选一里被刷到的概率。它的前提是把三选一改成等概率，见第一节。

---

## 一、三选一改成等概率

### 现在的规则

- 第 1~8 章：每关字池 = 到这关为止给过的全部字，逐关多一两个（教学节奏）。
- 第 9 章起：字池封顶，6 个底字 + 本章主题字，约 16 张（`StageCatalog.CappedPool`）。第 11、12 章沿用古寺。
- 池子内部再加权（`GameFlow.OfferWeight`）：本关新字没上过盘 26；成词另一半在盘上 22；盘上已有同字 16（半边字 12）；其余 10（半边字 6，万箭再压到六成）。

### 改成

| 条件 | 字池 |
|---|---|
| 账号还没通关第四章（字卡没开） | 维持现状，逐关给字教学 |
| 字卡开放后：主线、精英、无尽、活动 | **账号已解锁的全部字**，不分章、不分主题。账号已解锁 = 账号打到过的最远关卡为止，所有关卡字池的并集 |
| 每日残局 | 不变。全服同一盘，也不吃插槽 |

- 删掉第 9 章起的主题封顶（`Act2Theme` / `CappedPool`），全部 30 张字一起进池。
- 基础权重**全部相同**。半边字不再打六折，万箭也不再单独压低；凑词难度改由「池子大 + 要两张」自然决定，想凑就靠字运。
- 局内两档保留：「盘上已有同字」和「成词另一半在盘上」。它们管的是这一局的升星和凑词，不是限制哪些字能出现。没有这两档时，30 张池子里同字三连几乎抽不到，升星会断。
- 「本关新字」那一档只在这关**还没首通**时保留，否则第 5~10 章新给的字在 30 张池子里只有约 10% 的露脸率，玩家碰不到就学不会。首通后去掉。

> 这三条例外不影响「每关不限制范围」：所有已解锁的字在任何关都能刷到，例外只是局内临时加权。若要彻底等概率，三档都删，代价是升星和凑词明显变难，需要重测第 9 章以后的裕度。

### 改完的基础概率

一次改装三选一，某一张字出现在三张里的概率（权重抽、不放回，蒙特卡洛 20 万次）：

| 池子大小 | 无加成 | ×1.3 | ×1.6 | ×2.0 | ×2.5 |
|---|---:|---:|---:|---:|---:|
| 24 张（第八章左右） | 12.7% | 16.0% | 18.9% | 23.1% | 27.5% |
| 30 张（全开） | 10.0% | 12.7% | 15.3% | 18.8% | 22.7% |

另外 5 张字也挂满 ×2.5 时，30 张池里目标字回落到 18.5%。字运自带稀释，养得越平均，单个越不突出，不需要另设总上限。

## 二、插槽数量

插槽跟字卡品质走，复用第一版的等级档：

| 等级 | 品质 | 插槽数 |
|---|---|---:|
| 1–3 | 普通 | 1 |
| 4–6 | 高级 | 2 |
| 7–10 | 稀有 / 传说 | 3 |

- 插槽在升到对应等级时自动刷出类型，不用另开。
- 开放：通关第五章（45 关）。那时字卡上限 5 级，第二个槽已经够得着。
- 试用 +3 级不加插槽，只看真实等级。

## 三、插槽类型

共 7 种。字运、锋芒、烈度、广域这四种每个字都能刷出。持久、位移、贯通要这个字自己有那一项数才进池。

| 类型 | 谁能刷到 | 作用 |
|---|---|---|
| 字运 | 全部 | 三选一里这个字的权重 × 倍率；词作用在两个半边字上 |
| 锋芒 | 全部 | 带这个字（或成了这个词）的炮弹，整发伤害 +%。和字卡等级加成相加 |
| 烈度 | 全部 | 只动这个字自己的那一项，见下表。不提高同一发上其他字的伤害 |
| 广域 | 全部 | 有半径的字乘半径；没有的字多一块溅射，见第四节 |
| 持久 | 有时长的字 | 状态或硬直时长 +%。火毒冰水雷晕惑破、土 |
| 位移 | 会推拉的字 | 推拉距离 +%。土、风、聚、击退 |
| 贯通 | 会衰减的字 | 多段命中少衰减，加百分点，封顶 1.0。分、穿、炸、连斩 |

追和速不再单开类型。追的转向 1 星已经是 2.4、3 星 6.4，再快一截还是锁得住。速的飞行 3 星是 1.5 倍，金印章大约到 2 倍，看着快一点，打中的结果不变。这两张字的强度走烈度。

锋芒和烈度不是同一个数。锋芒加的是整发炮弹的最终伤害，一发上带的每个字都吃到。烈度只加这个字自己那一项：追的烈度不提高同一发上火的灼烧。

雷的连带数、分的路数、穿的穿透数、毒的层数、万箭的箭数、连斩的跳数，这些整数都不做插槽。

### 烈度：每个字提高哪个数

每个字只绑一个数，而且这个数不拿去给持久、广域、位移、贯通用。两种算法：

- **乘**：字自己有这项强度，强度 × (1 + 印章百分比)。
- **加点**：没有能独占的强度数。烈度就是「吃到这个效果的目标额外受伤」，数值直接用印章上的百分比，基础是 0。冰、雷、晕在目标被定住期间生效；土、风、聚、击退在推开或拉动之后两秒内生效。

| 字 / 词 | 烈度提高的数 | 算法 |
|---|---|---|
| 金 | 加算伤害 | 乘 |
| 重 | 乘算里超出 1 的那截 | 乘 |
| 木 | 吸血比例。不加每波回血上限 | 乘 |
| 火 | 灼烧每秒伤害 | 乘 |
| 毒 | 中毒每秒伤害 | 乘 |
| 冰 | 冻结期间受到的伤害 | 加点 |
| 水 | 减速幅度（1 − 剩余移速） | 乘 |
| 雷 | 被雷打中的目标受到的伤害，连带的也算 | 加点 |
| 晕 | 晕眩期间受到的伤害 | 加点 |
| 惑 | 被惑的怪咬同伴更狠；头目被惑时减速更多（上限 90%） | 乘 |
| 破 | 易伤比例 | 乘 |
| 土 | 被推开之后两秒内受到的伤害 | 加点 |
| 风 | 被吹开之后两秒内受到的伤害 | 加点 |
| 聚 | 被拉过来之后两秒内受到的伤害 | 加点 |
| 分 | 每发裂弹的伤害。衰减仍归贯通 | 乘 |
| 追 | 这发追踪弹自己的伤害 | 乘 |
| 速 | 这发加速弹自己的伤害 | 乘 |
| 穿 | 每一段穿透的伤害。衰减仍归贯通 | 乘 |
| 返 | 折返那一程的伤害系数 | 乘 |
| 炸 | 爆炸伤害。半径归广域，衰减归贯通 | 乘 |
| 秒杀 | 斩杀血线，普通怪和头目一起乘 | 乘 |
| 万箭 | 每箭伤害。箭数不加 | 乘 |
| 击退 | 被击退之后两秒内受到的伤害 | 加点 |
| 连斩 | 每一跳的伤害。衰减仍归贯通 | 乘 |
| 千钧 | 按当前生命追加的那段伤害 | 乘 |

冰挂一枚金烈度，就是冻结期间受伤 +22%。追挂一枚金烈度，是追踪弹自己的伤害 ×1.22，同一发上别的字不加。

### 每个字还能刷出的专属类型

字运、锋芒、烈度、广域每个字都有，表里只列另外三种。

| 族 | 字 / 词 | 专属类型 |
|---|---|---|
| 伤 | 金、重、木 | 无 |
| 状 | 火、毒、冰、水、雷、晕、惑、破 | 持久 |
| 位 | 土 | 位移、持久 |
| 位 | 风、聚 | 位移 |
| 道 | 分、穿 | 贯通 |
| 道 | 追、速、返 | 无 |
| 域 | 炸 | 贯通 |
| 词 | 秒杀、万箭、千钧 | 无 |
| 词 | 击退 | 位移 |
| 词 | 连斩 | 贯通 |

### 刷出概率

每个插槽独立抽一次，权重加起来是 100：

| 类型 | 权重 |
|---|---:|
| 字运 | 12 |
| 锋芒 | 22 |
| 烈度 | 22 |
| 广域 | 22 |
| 专属类型 | 合计 22，这个字有几种就平分 |

没有专属类型的字，那 22 平分给锋芒、烈度、广域，字运不变。

| 专属数 | 字 | 字运 | 锋芒 | 烈度 | 广域 | 每种专属 |
|---|---|---:|---:|---:|---:|---:|
| 无 | 金、重、木、追、速、返、秒杀、万箭、千钧 | 12% | 29% | 29% | 29% | — |
| 1 种 | 火、冰、水、分、炸、击退等 | 12% | 22% | 22% | 22% | 22% |
| 2 种 | 土 | 12% | 22% | 22% | 22% | 11% |

- **字运每个字最多一个。** 已经有字运的字，其余插槽抽中字运时重抽。这样一个字的出现率封顶 ×2.5，不能靠三个字运叠爆。
- 其他类型可以重复，三个槽都是锋芒也行，数值见下节。
- 三个槽里至少有一个字运的概率约 1 − 0.88³ ≈ 32%。想要哪个字有字运，多半得花钻石刷新。

### 刷新

- 一次刷新这个字上所有已解锁的插槽，只换类型。先把镶着的印章卸下退回背包，再重抽，不损坏。
- 只花钻石，每次 10，不限次数，不按槽数加价。没有广告刷新。
- 点右上角的刷新图标会先确认：把当前已开放的插槽全部重刷，镶着的会先卸下。
- 刷新时不保底，也不排除当前类型（可能刷出同一个），以免玩家觉得被操控。
- 字运仍然每个字最多一个。刷新时先把这些槽清空，再按顺序重抽。

## 四、印章

印章 = 类型 + 品质，数值只看品质，不洗练。类型必须和插槽对上才能装。

### 数值

| 类型 | 绿 | 蓝 | 紫 | 金 |
|---|---:|---:|---:|---:|
| 字运（权重倍率） | ×1.3 | ×1.6 | ×2.0 | ×2.5 |
| 锋芒（整发伤害） | +2% | +3% | +5% | +8% |
| 烈度 | +6% | +10% | +15% | +22% |
| 持久 | +8% | +12% | +18% | +25% |
| 广域 | +5% | +8% | +12% | +16% |
| 位移 | +8% | +12% | +18% | +25% |
| 贯通（衰减加百分点） | +3 | +5 | +7 | +10 |

- 同类型的多个印章在同一个字上**相加**。三个金锋芒 = +24%，加上满级字卡的 20% 一共 +44%，是单字的天花板。
- 广域按半径加，面积约是半径加成的两倍，所以百分比档位压得最低。水、雷、聚、炸乘在自己的半径上。没有半径的字，广域不走这列百分比（乘在 0 上没有效果），改成溅射半径：绿 0.4 / 蓝 0.55 / 紫 0.7 / 金 0.85 格，溅到的怪吃这一发的五成伤害；同一发上几个字的溅射相加，封顶 1.2 格。水的基础半径是 0.9，金广域的单体字刚好贴到身边那只，盖不过天生的范围字。冰、晕、惑也走这条，金广域的冰是贴身再冻一只。
- 品质之间的差距故意拉开：金印章大约是绿印章的 3~4 倍。日常拿到的是绿和蓝，金是惊喜。

### 金印章是运气惊喜

金印章只占普通掉落的 2%，再落到指定类型是 1/7。以秒杀为例，三星秒杀的斩杀血线：

| 秒杀槽里的烈度印章 | 无 | 绿 | 蓝 | 紫 | 金 |
|---|---:|---:|---:|---:|---:|
| 非头目血线 | 60% | 64% | 66% | 69% | **73%** |
| 头目血线 | 40% | 42% | 44% | 46% | 49% |

拿到一枚金烈度印章的概率：通关第五章后的每日残局，和银箱，每枚 2% × 1/7 ≈ 0.3%；金箱约 0.6%；皇家箱约 1.1%。残局要 20 波全部守住才给那一枚。秒杀没有专属类型，每个槽刷出烈度的概率约 29%，三个槽里至少一个烈度约 65%。所以 73% 不压，真刷到就是玩家的高光时刻。

镶上金印章时，详情页和局内落字飘字都单独放一个金色演出，让人知道这次运气好。

### 来源

| 来源 | 掉落 | 品质分布（绿 / 蓝 / 紫 / 金） |
|---|---|---|
| 每日残局 | 通关第五章后，20 波全部守住才给 1 枚，转盘转到它。之前是 10 波木箱、20 波银箱 | 60 / 28 / 10 / 2 |
| 银箱 | 15% 掉 1 枚 | 60 / 28 / 10 / 2 |
| 金箱 | 35% 掉 1 枚 | 45 / 35 / 16 / 4 |
| 皇家箱 | 必掉 1 枚 | 0 / 60 / 32 / 8 |

关卡首通、精英首通不掉印章。木箱、炮台宝箱不掉。

印章类型按 7 种平均抽，不按玩家的槽来定向。

每日残局通关第三章就开。通关第五章之前，撑过 10 波给木箱、20 波给银箱，不直接给印章。通关第五章之后不再给箱子，20 波全部守住才给 1 枚。字卡页的「印章」入口在背包里有东西时就出现。开箱掉落从字卡开放（通关第四章）起。插槽也是通关第五章才开。无尽、活动不掉。

### 分解

不要的印章分解成金箔：绿 2 / 蓝 5 / 紫 12 / 金 30，金箔拿去升字。刷新插槽花钻石，不花金箔。

## 五、界面

定稿是「丙 · 星尘」版原型：字浮在放射光里，外圈一圈金色星尘，三颗槽是小圆章。圆章和纹样的提示词在 `docs/prompt/ui/seal_medal_v3_prompt.txt`、`seal_icons_v3_prompt.txt`，原图在 `game_assets/black-rosa/ui/seal/`。

| 图 | 用途 |
|---|---|
| `seal_q_green` / `blue` / `purple` / `gold` | 镶好的印章：四色圆章，纹样原色压在中间 |
| `seal_ico_*` | 七种类型的纹样，星星、矛头、火苗、波纹、沙漏、风、箭 |
| `seal_empty` | 刷出了类型、还空着的槽：一枚金币，中间压类型纹样 |
| `seal_stud` | 没到等级的槽：一颗小灰珠 |
| `seal_dust` | 外圈星尘的小金点 |

### 字卡页

- 金箔药丸左侧加「印章」，和右侧「兑换」对称，点开印章背包。插槽开了、或背包里有印章时才出现；有新掉的印章时挂红点。
- 镶了字运的字，列表卡右下角加一枚小红印「运」。试用角标不动，两个可以同时在。
- 列表卡的红点除了「能升级」，再加「有空槽、背包里正好有这种印章」。底部字卡页签的红点也算上这两条和新印章。

### 详情

- 板高 1060。右上角一枚单独画的刷新图标，底下标 10 钻。下面一块放射光。字不套卡框，词是两个字并排，是这一屏唯一的大东西。左右箭头在同一分类里切换。字下面不再放家族和本事说明。
- 等级药丸和十颗等级点在上，下面一行写「字的整体伤害 +14% → +16%」。金箔价格贴在升级按钮上沿，整行居中。
- 槽边两行：类型名，下面写「提高什么 + 加多少」，例如「整发伤害 +5%」「裂弹衰减 -10%」「出现率 ×1.6」。数按镶着的品质变，用品质色。空槽写「整发伤害 可镶嵌」或「整发伤害 空」。
- 光外面一圈 34 颗金色星尘，下沿和三颗槽附近留空，几颗慢慢呼吸。三颗槽落在上、左、右，第一颗在上面最显眼。
- 三颗槽的样子：
  - 未到等级：灰石钉，下面写「Lv.4」或「Lv.7」。点一下提示「升到 N 级开这颗槽」。
  - 刷出了、还空着：空金币压着类型纹样，下面写类型和「可镶嵌」或「空槽」。背包里有这种印章时轻轻呼吸。
  - 镶上了：品质色章面 + 金边 + 纹样，下面写类型和数值，例如「烈度 +10%」。金印外面一圈慢转的光。
- 第五章前三颗都是石钉，光的下方写「通关第五章开放插槽」。
- 右上的刷新图标花 10 钻石，不限次数，一次换掉所有已解锁的槽。点下去先确认。第五章前、或一个槽都没开时不显示。
- 点中一颗：它外面亮一圈光，从底部弹出这颗槽的镶嵌面板。
- 镶嵌面板只负责装和卸。左边是这一槽现在的印章，右边是类型、「金印章 · 整发伤害 +8%」（空槽写「镶上后整发伤害提高」）、一句完整效果加「品质越高，加得越多」。下面四格绿蓝紫金，各写这个品质加多少和背包里的数量，镶着的那格顶上写「镶着」。点一格就镶，原来那枚回背包。有印章时底部可以卸下。
- 刷新可能刷出同一种；槽里的印章回背包。金印镶上时多放一段金色火花和彩纸。
- 词的字运说明写成两个半边字都会更容易刷到，例如「万和箭都会更容易出现」。
- 升级动画的白闪改成一团圆光，没有卡框了。升到 4 级、7 级时新槽弹出来，并提示「开了新插槽：X」。

### 印章背包

- 从字卡页左上角进入。顶上按类型筛：全部、字运、锋芒、烈度、广域、持久、位移、贯通。
- 相同类型、相同品质叠成一格，写数量，金的排前面。装进槽或分解时从这一格扣一枚。
- 背包里不能直接镶，点一格只提示这种印章做什么。镶只发生在某张字的槽上。
- 「分解印章」进分解模式：点一格选一枚，再点继续加，选满再点清零；可「选全部绿」。底部写「已选 N 枚 · 得 M 金箔」。选了紫或金要再确认一次。绿 2、蓝 5、紫 12、金 30。
- 打开背包就清掉新印章红点。

### 掉落和局内

- 关卡首通不发印章。通关第五章后，每日残局全部守住时，结算在收获处转一圈转盘，转到已经入账的那一枚，中间写「锋芒 · 绿」。没守住不转、不给印章。通关第五章前残局仍给木箱和银箱。开箱页仍可在奖励那一排放印章卡。
- 开箱时印章和墨、金箔排在同一行小签里。
- 装上金印时，详情槽和当次落字飘字放一段金色，不另开全屏。
- 落字飘字只在有锋芒时，于「Lv.N +X%」后面加「锋芒 +Y%」。烈度、广域这些不写进飘字。
- 字运不出现在局内，也不写在三选一的牌上。玩家在字卡页的「运」和槽里看到它。

## 六、实现要点

- 数据：`SealCatalog`（类型、品质、数值表、每字可刷范围、刷出权重、掉落、文案）。字和词共用一个下标 `key`，词排在 30 个字后面。
- 存档（`MetaProgress.Seal.cs`）：`SlotType[]`、`SlotSeal[]` 按 `key × 3 + 槽号` 平铺，`SlotSeal` 存品质 + 1（0 = 空）。印章不分个体，背包是 `SealBag[类型 × 4 + 品质]` 的计数。另有 `SealNew`（红点）。全是公开字段，云存档整包同步。`Normalize` 补齐长度，槽开了就当场刷类型，每个字最多一个字运。
- 三选一：静态字池不动（`check_stages.py` 照旧），开局时 `MetaProgress.AccountPool` 算出账号已解锁字池给 `GameFlow`；`OpenWeight` 等权重 + 局内两档 + 首通前新字，最后乘 `OfferLuck`。词的字运按两个半边字算，取最大。
- 战斗：开局 `TakeSeals` 打包成 `SealPack` 交给 `BattleWorld`，每日残局给 null。`ShotMul` 在等级加成上加锋芒。烈度：有强度数的乘系数；冰雷晕在 `HardAmp`（定住期间），推拉类在两秒的 `MarkAmp`。广域有半径的乘半径，没有的走新的 `HitSource.Splash`。持久、位移、贯通在读 `GlyphDef` / `WordDef` 的地方乘系数。落字飘字有锋芒时加「锋芒 +Y%」，金印飘金色。
- 界面：`GlyphDetailPanel`（星尘详情 + 镶嵌面板）、`SealBagPanel`（背包和分解）、`SealArt`（印章三层叠图），结算 `VictoryPanel.BuildSeals`、开箱 `ChestOpenView` 小签。GM 栏「印章各来一套」每种每品质发一枚。
- 难度：插槽是新的强度来源，`HpMul` 还没重算。上线前按「每个常用字两个蓝印章」重算第 6~12 章的预期，再看 6 份通关存档的裕度。
