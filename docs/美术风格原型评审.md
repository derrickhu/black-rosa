## 分套

### A · 宣纸图章

最贴策划「白纸底、颜色后到」。

- Gemini `00` / `02`：纸面空、几何章、中列火/冰、其余近黑白。这是三套里最接近生产锁的母版。
- Gemini `01`：2×4 关卡章 + 锁，骨架对；不该写「墨弹」，未解锁格有时画成空花纹而不是空印。
- Gemini `05`：兵种轮廓可用（滴 / 尖 / 环 / 簇 / 菱 / 爆 / 方印），但格子上写了 1–9。
- Gemini `06`：火冰追爆色对，多出格子和重复针/炮，4×4 而不是 4×3。
- Cursor `02`：更像水墨海报，左右会生山门、纹样边，违反「战场不加风景框」。适合宣发心情，不适合当 UI 母版。

**留下来的**：Gemini 的纸、中列上色、砚台短管。丢掉：图内数字、风景框、牌表多余格。

### B · 木刻街机

计划要「块大、套色油墨」。实际两模型都偏手绘粗线，狠度不稳。

- Gemini `00`：轮式连体炮、厚卡框、橙青套色，最像 B。
- Gemini `02`：改装大黑钮、中列火焰成立，但网格太高、线太草，和 A 差一档而不是换体系。
- Gemini `06`：炮牌容易画成手枪剪影，不能当生产表。
- Cursor：框更重、更「成品 UI」，黑块有了，但仍不是木刻海报。

**结论**：B 还没从 A 里独立出来。若选「要狠」，不要直接采用现在这套，要重写风格块（更大色块、更少草线、禁止手枪）。

### C · 萝卜剪影

最好认、最像能上微信的超休闲。

- Gemini `00` / `02`：圆角格、墨罐炮、滴/鼠/甲虫/团子，中列仍只有改装色。方向对。
- 风险已出现：敌开始长眼睛、表情；Gemini `02` 把英文风格名写进顶栏。再松一步就会变成普通休闲皮肤，纸+后上色会丢。
- Cursor 更圆、更像现成小游戏截图，壳可以用，生产时仍要禁粉彩全身。

**留下来的**：圆触控、物种剪影、胶囊 CTA。锁死：一期敌人不许上色、不许表情、不许把风格名画进图。

1. 列数/层数漂：计划 5 列 × 开 1～3 层，模型爱画满屏格。

4. 命中特效仍带描边；圣经写的是闪光不描边。
5. Cursor 爱给纸战场加远景。
