# 字卡

通关第四章（36 关）后开放的局外养成。花「金箔」给已收录的字和词升级，吸收后期多出来的炮台碎片、道具卡和墨。变现只走激励视频。

代码：`Data/StudyCatalog.cs`（数值）、`Core/MetaProgress.Study.cs`（存档和规则）、`UI/StudyPage.cs` / `GlyphDetailPanel.cs` / `BagPanel.cs`（界面）。

## 第一版做了什么

- 底栏最左边加「字卡」页签（编号 `HomeScreen.TabStudy = 4`，摆位由 `TabSlots` 决定）。没开放时灰着带锁，点了提示「通关第四章开放字卡」。
- 字卡页：金箔贴在体力栏下面，点它在栏下弹出一小条获取说明（首次通关 / 每日签到 / 开宝箱 / 满级碎片自动转换 / 每日兑换），点任意处关掉；右边是兑换图标，每天可以用墨换金箔，也可以用 40 钻石换 20 金箔一次。分类（全部 / 伤害 / 状态 / 位移 / 弹道 / 范围 / 词）；四列卡片，已有的在前，没有的显示「第 N 章出现」。
- 详情：大卡、说明、伤害加成「现在 → 下一级」、十格等级条（上限外的格子灰掉）、升级、看广告试用。「插槽」「攻击特效」先摆「即将开放」。

## 效果

一级 = 带着这个字（或这一发成了这个词）的炮弹，整发伤害 +2%。一发带好几个字时取这几个字等级的平均。满级 10 级 = +20%。

- 乘在 `FinalMul` 旁边：`BattleWorld.ResolveHit`、箭雨 `RainDamage`、皮肤回响 `SkinEcho` 三处。
- 成词的半边字（秒、杀、万、箭……）不单独升级，升的是词本身。
- 每日残局不吃字卡（大家同一盘）。无尽、活动照常吃。

## 品质与局内表现

等级分四档品质，颜色和道具卡品质一致，传说另用金色（`StudyCatalog.TierOf / TierColor / TierDeep`）：

| 等级 | 品质 | 颜色 |
|---|---|---|
| 1–3 | 普通 | 绿 |
| 4–6 | 高级 | 蓝 |
| 7–9 | 稀有 | 紫 |
| 10+ | 传说 | 金 |

局内（`BattleView.PaintStudy / PaintHalo`）：

- 棋盘上升过级的字：外圈一道品质色框，左上角一块深色等级牌写「Lv7」。蓝档开始字下垫一团同色光；紫、金两档的光和框会呼吸；金档的框会闪，还有一颗亮星沿框绕圈。
- 试用的字或词：框和等级牌都换成青色，牌上写「试N」，N 是加上试用后的等级。
- 落字时冒一行飘字「Lv.N +X%」（试用写「试用 Lv.N +X%」），成词时在上面再冒一行词的等级。紫档以上的飘字更大。
- 炮弹：按这一发的字卡平均等级，在弹体下面垫一圈品质色光，等级越高越大越亮。
- 开局有试用时，先弹一条提示「今日试用 · 某字 +3 级」。这一局没把这个字放上去、也没凑出这个词，试用还在。
- 字卡页和详情页的卡框、等级牌、等级点都用同一套品质色；详情页标题写「稀有品质 · ……」。

| 广告位 | 作用 | 次数 |
|---|---|---|
| `glyph_trial` | 选一个已有的字，今天 +3 级（可以超过上限，最多 13 级）。只在当天有效。这一局没出现、或出现了没放上去，试用还在；放下这个字、或凑出这个词，才算用掉。过了今天还没用，直接清掉。已经挂着没用的试用时，再换别的字要先确认，确认后才清掉旧的并再扣一次 | 每天 2 次 |

## 难度校准

前四章一点不动。第五章起，主线和精英的怪血在出生时（`BattleWorld.Make`）乘 `StudyCatalog.HpMul`：

```
HpMul = 1 + 0.02 × 预期等级
预期等级（第 1~10 章）= 0 0 0 0 1 2 3 4 5 6
```

补满预期加成：升到预期等级的人难度持平，一级没升的人第十章约紧 12%。乘在出生血量上而不是 `StageDef.Hp`，掉落按 `HpAt` 算，经济不受影响。`check_stages.py` 会打印两条裕度曲线（升到预期 / 一级没升）并检查前四章预期等级为 0、怪血倍率不超过 1.2。

### 线上数据校准（2026-10）

拉了通关最多的 6 份云存档：3 人 90 关全通、4 人打穿无尽 70 波（有一人才 78 关、改装没满），主线几乎全三星；精英 6 人里 5 人只打了 0~6 关；改装满了之后墨没处花，有人攒着 5 万。原来每级 +3%、怪血只补七成，后期会更松。这一轮：

- 字卡每级 +3% → +2%，怪血补满。
- 主线后期补强 `StageCatalog.ChapterLateHp`：第 6~10 章出怪血 ×1.14 / 1.05 / 1.18 / 1.28 / 1.42，第五章起裕度拉平到约 9.5（原来一路涨到 13.45）。精英吃同一份。
- 无尽后段 `StageCatalog.EndlessLateHp`：第 30 波起抬，第 40 波 +30%，第 70 波 +40%。每日残局不受影响。
- 两项补强都只乘在 `BattleWorld.Make` 的出怪血量上，掉墨、掉金、关卡定价不变。
- 改装门槛过 45 关的级墨价 ×1.6。90 关内开放的级合计 41250，约等于首通一遍且每关都看双倍的进账，买满得去打精英或重刷。

## 存档字段（`MetaProgress`）

`Foil`、`GlyphLevel[]`（按 CardId）、`WordLevel[]`（按 WordId）、`StudyDay` / `SwapCount` / `SwapAdDone` / `TrialCount`（每日计数）、`TrialKind` / `TrialId`（今天还没打出来的试用，过天清掉）、`StudySeen`（开放后点开过没有，底栏红点用）。`NormalizeStudy` 补齐长度并夹回 0~10。
