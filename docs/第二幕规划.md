# 第二幕规划

八章之后的内容扩展、新字新词、长线运营系统和版本顺序。数值是起步值，落地时以各自的数值文档为准：关卡看 [关卡设计](关卡设计.md)，局外看 [局外成长](局外成长.md)，字效看 [字效管线](字效管线.md)，敌人看 [敌人设计](敌人设计.md)。

**总原则不变：局外绝不强化字牌。** 深度来自玩法变化和收集，不来自字越养越强。

## 一、八章之后的关卡：第二幕「魔渊篇」

第 9 到 16 章，每章仍然 9 关。

### 可以接的三个钩子

- 第一到第八章第三排从没全开过，「三排全开留给以后的章节」。这是最自然的新盘面。
- 墨王是第八章的终点；无尽模式里已经有「魔气入侵」和被魔化的莲池，美术和设定都铺好了。
- 伤害线在第 69 关就点满，打完第八章局外没有往后走的东西。

**剧情一句话：** 墨王只是被魔气附身的傀儡，玩家顺着魔气一路追到源头「墨渊」。

### 三条新的递进线（和第一幕错开）

1. **盘面：第三排全开，变成 18 格。** 一列三格全开，才放得下「三字诀卷」（整列卡）。
2. **魔化：给现有敌人加词缀，不新画怪。** 魔化的怪换洋红眼加一对小角（贴图叠一层），挂一个词缀：
   - 魔盾：开场挡一发；
   - 魔隐：周期隐身；
   - 魔速：移速 +25%；
   - 魔护体：受伤 -12%（即无尽里的魔气减伤）；
   - 魔污：死后污一格。

   第一幕 25 只怪都能魔化，第二幕怪量主要靠它撑。参考暗黑精英词缀、《王国保卫战》英雄挑战。
3. **格子机关：第一次让格子本身成为题目。**
   - 碑字格：预先刻好一个字，不能换。
   - 金框格：放进去的字按高一星算。
   - 污格：被敌人涂黑后暂时失效。
   - 夜战：上半场看不见，火、炸、雷打出去才照亮。

### 数值怎么接

- 章节血量基数接着往上：3.1、3.4、3.7、4.0、4.35、4.7、5.1、5.5（第八章 2.8）。
- 伤害线再加 6 级，门槛铺到 80–140 关。
- 新开两条通用词条：改装折扣、道具冷却。
- 道具栏第四格放在通关第 12 章。
- 无尽第 50 波现在钉 14 倍；第二幕上线时按最新章底重锚一次，约章底的 2.5 倍。

**发布节奏：** 两章一版，三到四周一版。

## 二、新字和新词

### 硬约束（现有规则推出来的）

- 一列只有三格，一个词占两格，所以**一列最多醒一个词**。
- 炮弹表现只有五个槽位：体、尾、环、绕、晕光。新字必须找到自己的槽。
- 硬控同时只生效一个，优先级冻 > 晕 > 惑；位移同轴取最大、异轴都执行；范围伤害不再触发范围。
- 招牌两两目前封顶 12 张。
- **已有单字不再拿去当词的一半。** 第一幕四个词（秒杀、万箭、击退、连斩）两个字都是新字，继续守这条，否则「雷」一会儿常驻、一会儿要等伴侣才醒，玩家说不清醒没醒。

### 否掉的字

| 字 | 原因 |
|---|---|
| 冻、燃、焰、爆 | 和冰、火、炸意思重复 |
| 暴 | 和赤焰皮肤专属词条「暴击」撞名 |
| 连、击、退 | 已是连斩、击退的一半，单独出会让判定变糊 |
| 回 | 和道具「回旋镖」撞 |
| 盾 | 和敌人「挡一发」的盾读法冲突 |
| 天雷、冰封这类词 | 违反「单字不当词的一半」 |
| 光、照 | 隐身怪改成「被打中就显形」，不需要照明字 |

### 7 个新单字

**破（状态族，易伤）**
- 常驻。被打中挂 3 秒「破防」，受到的所有伤害 +15% / +25% / +35%；三星直接打掉「挡一发」的盾，这一发继续结算。
- 结算在暴击之后、甲之前，所以对厚甲、铁桶、墨王有实打实的作用；灼烧和毒每跳也吃加成。
- 冲突：和「穿」意思接近，卡面写「破防：挨打更痛」，炮弹走环槽，靠形状区分。
- 结合：重（招牌「崩山」）；能抵掉魔护体的一截减伤。

**聚（位移族，向心）**
- 命中后半径 0.6 / 0.8 / 1.0 内的敌人被拉向命中点 0.3 / 0.45 / 0.6 格；三星多 0.3 秒落地硬直（同土，不算硬控）。关底拉不动，但会把周围的怪拉到关底身边。
- 冲突：新的第三种位移「向心」。和土、击退（沿列推）异轴，照常一起执行。和风同发不取大，直接合成招牌「旋风」。
- 结合：炸、雷、万箭、惑——怪越挤越值。

**返（弹道族，折返）**
- 子弹飞到场顶或穿透次数用完，折返往下飞一次，伤害 ×0.6 / 0.75 / 0.9。
- 折返段到格子上沿消失，不重新吃格子里的字，不计入蓄力。和「分」叠时每股都折返，但每股折返伤害封顶 ×0.5。
- 冲突：名字不用「回」，避开回旋镖。
- 结合：穿（招牌「回锋」）；顺手守漏怪线。

**封（状态族，封印特性）**
- 打中后 2 / 3 / 4 秒内敌人的技能全部失效：回血光环、半血狂暴、死后分裂、隐身、施盾、加速光环。关底时长减半。
- 不进冻 > 晕 > 惑排位，不触发防连晕，可和硬控同时挂。
- 只封技能，不封身体特性（甲、免击退、免定身），留给破和重击处理，避免一个字通吃。

**影（弹道族，回响）**
- 每发母弹之后 0.2 秒补一发影弹，伤害 ×0.4 / 0.5 / 0.6。
- 影弹**只继承常驻字**，不继承蓄力字和词，否则秒杀变两发、万箭变两场。影弹不计蓄力，不再生影。
- 和「分」叠时子弹数翻倍，要封性能上限；厚甲每发减伤正好克它，是有意的克制。

**财（经济向，本身不加伤）**
- 这一列打死的怪金币 +1 / +2 / +3，关底 ×3；墨不加。
- 在「现在变强」和「之后抽更多牌」之间做选择，类似《Balatro》加钱的小丑。
- 冲突：五行的「金」容易被当成钱，所以字面用「财」，金的卡面继续写「加伤」。和福袋皮肤金币收益相乘；无尽单独设上限。

**护（新开「守」家族）**
- 这一列每波第一只走到漏怪线的怪被弹回 1.5 格并定 1 秒，基地不掉血；二星每波 2 次，三星弹回时再炸一圈。
- 只护自己这一列。关底撞线照样扣血。
- 和木的区别：木是掉血后补回来，护是掉血前挡掉，可并存。

### 4 个新词（两个字都是新字，一列只醒一个）

| 词 | 蓄力 | 效果 | 和现有内容的关系 |
|---|---:|---|---|
| 千钧 | 3 发 | 扣目标当前生命 8% / 12% / 16%，关底按一半 | 千钧先削，秒杀收尾；两词只能放不同列，逼玩家规划两列 |
| 斗转 | 3 发 | 打中的敌人掉头往回走 1.2 / 1.6 / 2 秒 | 和土、击退同轴，但按时间算，直接覆盖；冻、晕期间时间照扣 |
| 横扫 | 3 发 | 从命中点向左右扫一道横波，同一水平带的怪吃 ×0.6 / 0.8 / 1.0 伤 | 炸是圈，横扫是一整行，专治六列同时压线 |
| 裂地 | 4 发 | 命中处留 2 秒地裂，走过的怪每秒受伤并减速 | 第一个持续地面区域；顺手补上「烈爆」没做成的真火地 |

沿用秒杀、连斩的「发光弹」路线，和单字的平涂炮弹拉开。

### 三字诀卷（第三排全开之后）

**占满整列三格的卡。** 只能放在三格都开且都空的列，改装时稀有出现，一局一到两次。

- **穿云箭**：这一列每 5 发打出一支贯穿全场的大箭。
- **金钟罩**：每波挡 3 次漏怪，加强版的护。
- **风火轮**：炮弹变成在这一列来回滚的火轮。
- **定海针**：每 6 秒落一根针，周围怪减速 60%。

取舍：诀卷很强，但这一列不能再放字、不能成词。

### 新招牌两两（上限 12 → 18）

| 组合 | 名字 | 效果 |
|---|---|---|
| 破 + 重 | 崩山 | 破防的目标吃重击时无视甲 |
| 聚 + 炸 | 坍缩 | 先拉后炸，炸圈半径 +30% |
| 风 + 聚 | 旋风 | 同轴冲突改成合成：先卷成一团，再整团吹到邻列 |
| 返 + 穿 | 回锋 | 折返段穿透 +1，伤害不衰减 |
| 封 + 惑 | 失魂 | 惑的时长 +50%，期间技能全封 |
| 影 + 火 | 鬼火 | 影弹的灼烧按 100% 算 |

代价是多画 6 张炮弹专图，《字效管线》「封顶 12 张」跟着改。

### 字池稀释

第八章字池 25 张，全加进去到 40 张，三选一抽到另一半凑词的概率掉一半左右。

从第 9 章起**每关字池封顶约 20 张**：
- 6 张底盘字；
- 8–10 张本章主题字（成对的词仍同关一起给）；
- 2–4 张由玩家的「字帖」带进来（见第三部分）。

## 三、长线运营系统

### P0：第一个大版本，几乎全复用现有代码

1. **困难模式「重描」。** 已三星的章节开困难版，每关敌人带魔化词缀，奖励墨和字体。参考《王国保卫战》英雄 / 钢铁挑战、《保卫萝卜》。一套关卡用两遍，美术成本接近零。
2. **每日残局。** 全服同一个种子、同一个开局，打完上榜，分享写「我撑到第 N 波」。参考《羊了个羊》每日一关和《杀戮尖塔》每日挑战。复用无尽的固定种子和排行榜云函数。
3. **无尽每周魔气词缀。** 每周换一条规则（怪死后分裂、金币翻倍但字池少几张……），每周清榜。参考《Hades》热度、大秘境词缀。
4. **每日功课。** 「用火打死 50 只」「叠出一次招牌两两」之类，奖励墨。作用是推玩家试没用过的组合，新字才有人碰。

### P1：一到两个版本

5. **文房四宝开局。** 开局四选一：笔（三选一变四选一）、墨（开局送一张随机常驻字）、纸（第三排先开一格）、砚（金币 +15%）。成就解锁。参考《Balatro》牌组、《土豆兄弟》选角：每局玩法不同，但不强化任何字。
6. **字帖。** 收藏几张字让它们更容易抽到，封存几张让它们不出现。参考《吸血鬼幸存者》放逐 / 封印。既解决字池稀释，也让玩家规划流派。
7. **笔意（书法字体皮肤）。** 楷、隶、篆、行、草、瘦金体，换卡面和炮弹字形，零数值。这款游戏独有的收集点，分享图也好看。
8. **墨韵令。** 28 天一季通行证，免费线 + 看广告线，不做付费。功课、困难模式、笔意的产出往这里汇。
9. **周联赛。** 每 30 人一组，按无尽或每日残局成绩每周升降级。参考多邻国联赛。

### P2：等前面跑顺了再做

10. **讨伐魔尊（全服世界 Boss）。** 全服共享一条血条，每人每天两次，按伤害发阶梯奖励。参考《咸鱼之王》《向僵尸开炮》。
11. **书院（公会）。** 每周书院 Boss，成员之间互送体力。参考《开心消消乐》送心。
12. **节日活动模板。** 元宵「猜灯谜」最贴题材，谜底就是字；端午、中秋套同一个模板。

### 明确不做

- 字牌局外升级、抽卡养成字牌——直接打掉 roguelite 每局从零开始的核心。
- 实时对战——成本高，和竖屏塔防不搭。

## 五、版本 1 落地记录

四样都做了，和上面 P0 的出入写在各条里。日期和周号由 `DayClock` 统一算：日期是本机 yyyymmdd，周号是 2024-01-01（周一）起过了几个整周；云函数按北京时间算同一套，只收当期和上一期的成绩。

### 魔化词缀（重描、无尽「魔化」周、每日「魔化」日共用）

`BattleWorld.Demonize` 在出怪时掷一次，分裂出来的小怪不掷。魔化的怪叠一层洋红（`E040B8`，0.32）。

| 词缀 | 效果 |
|---|---|
| 护盾 | 带一层盾 |
| 疾行 | 移速 ×1.25 |
| 魔护 | 减伤 15% |

关卡侵染减伤和魔护相加，封顶 30%。重描的关底不掷，一律带 12% 魔护。

### 重描（困难模式）

- 开放：一章九关全部三星。章节卡左上角出现「重描」键，点了整张卡换成重描节点（洋红路线、按重描记星），翻到没开的章自动切回；打完回主页停在原章的重描页。
- 章内按顺序：第一关随章开，后面每关要先过上一关的重描。
- 关卡：布局、波次、字池原样，血量 ×1.5，35% 杂兵魔化，没有教学和新字预告。体力照主线收。
- 奖励：墨照主线公式按重描自己的星算；首通另给钻石，普通关 2、带关底的关 6、章底 15。不给星级宝箱，也不进新手指引。
- 没给字体奖励：笔意排在版本 3。

### 每日残局

- 开放：通关第四章。全服同一天同一局，入口是首页左列「每日」贴纸，和每日功课在同一页。
- 20 波，第 n 波按无尽第 round(1.6n) 波的血量、掉落、速度走，第 20 波约 9.6 倍血。不加格、不渗魔气。
- 第 10 波压一只中关底（墨囊 / 铁桶 / 双生 / 鼓手里挑），第 20 波压一只大关底（雷公 / 医者 / 守将 / 魔王里挑）。
- 盘面只开两排。开局在这两排随机摆四张单字，其中一张二星；另从第四章章底的字池里禁掉两张单字。
- 每天一条词缀，和本周无尽的错开。战场底图按日期从八章里挑。
- 次数：每天 1 次，看广告再加 1 次，不扣体力。
- 奖励：拾到的墨 + 每撑过一波 4 墨；撑过 10 波给木箱，20 波全守住给银箱。复活次数同无尽。
- 上「每日残局」榜，按当天最好波数排，换天清榜。

### 无尽周词缀

七条轮换，周号 ×3+1 取模，相邻两周不重复：

| 词缀 | 效果 |
|---|---|
| 疾风 | 移速 +15%，金币 +10% |
| 厚墨 | 血量 +20%，金币 +25% |
| 蜂群 | 怪量 ×1.3，血量 ×0.75 |
| 魔染 | 额外 6% 减伤，金币 +15% |
| 拮据 | 开局 +30 金，改装贵 20% |
| 魔化 | 30% 杂兵魔化，金币 +20% |
| 背水 | 基地 -1 血，金币 +40% |

- 无尽页加一行本周词缀和剩余天数，大字改成本周最好，历史最好挪到下面的小牌。

### 每日功课
