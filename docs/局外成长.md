## 总原则

成长切两层，边界不能破：

- **局内不动**：金币抽改装牌、字牌随机、叠星。这是 roguelite 的乐趣来源。局外**绝不**解锁或强化任何字牌。
- **局外只动两样**：开局条件（伤害、炮数、射速、开局金、基地血）和一局内的应急手段（技能）。
- 章节元素解锁（金木水土风雷毒惑）继续走 `StageCatalog.ChapterUnlocks` 按章免费放，**不卖**。
- 皮肤零数值。不卖强度。

## 体力

墨如果能无限刷，成长树一坐就点满，经济直接废掉。体力封住产出速度，见底就是广告位——用完不是赶客，是一次曝光。

| 项 | 值 | 常量 |
|---|---:|---|
| 上限 | 12 | `StaminaMax` |
| 重刷一关 | 2 | `StaminaPerStage` |
| 恢复 | 每 15 分钟 +1 | `StaminaRegenMinutes` |
| 空瓶到满 | 3 小时 | — |
| 广告补 | +6，每日 5 次 | `AdStaminaGain` / `AdStaminaPerDay` |
| 每日首胜 | +4 | `DailyWinStamina` |

**没通过的关不收体力**（`MetaProgress.StageCost` 判 `Stars[stage] > 0`）。推主线全程免费，只有回头重刷才耗。卡关的人也不会被双重惩罚。

**只有通关才真的扣**。进关时押 2 点，`GameFlow.ShowHome` 回首页时把还押着的退回去；通关那条路径先把押注清零。所以撤退、失败、失败后续命再通关，三种情况都算得对。

一天大致产出：初始 12 + 在线恢复 + 广告 30，重度玩家约 25 局，轻度 6–10 局。

**已知漏洞**：体力按 `DateTime.UtcNow.Ticks` 离线结算。把系统时间**往回**调挡住了（`now < StaminaTick` 时不恢复，只把锚点拉到当下）；**往前**调挡不住。要彻底堵得靠云存档时间戳，项目目前没有云存档，先不为它单独做工程。

## 新手礼包

首次进入（`StarterGranted` 为假时）一次性发：

- 体力给满 12
- **60 墨**（`StarterInk`），够立刻点掉 3 个第一级升级，第一分钟就有成长反馈
- 叠加「第一章首通免体力」，新手推主线完全不撞墙

日活钩子只用**每日首胜**：当次墨 ×2（免广告）+ 体力 +4。**不做签到面板**。

## 墨的产出

在 `MetaProgress.ApplyResult` 里算，返回值给 `GameFlow` 显示。

| 情况 | 公式 |
|---|---|
| 首通 | `4 + 关序号*2 + 星数*4` |
| 提星 | `(新星 - 旧星) * 4` |
| 重刷已满星 | 首通值的一半，至少 1 |
| 失败 | **0 墨**，改为全额退体力 |
| 每日首胜 | 上述 ×2 |
| 广告双倍 | 再 ×2，每次结算限 1 次 |

第 1 关 3 星 16 墨，第 8 关 3 星 30 墨。首章全 3 星首通共 **184 墨**。

失败不给墨是故意的：体力已经退了，等于免费重试，本身就是最好的安慰奖。如果既退体力又给保底墨，就出现「故意送掉刷墨」的漏洞。

## 星级判据

**按丢了多少血算，不是按剩多少血。**

```csharp
int lost = _world.MaxBaseHp - _world.BaseHp;
stars = _world.RevivesUsed > 0 ? 1 : (lost <= 1 ? 3 : 2);
```

3 血时和旧规则（`BaseHp <= 1` 给 2 星）完全等价，但局外加了基地血之后不会自动放水。这条改了策划案里钉的原规则。

## 炮台改造（5 条线）

`Cost[i]` 是从 i 级升到 i+1 级的价，`Gate[i]` 是那一级要求的总星。

| 线 | 每级 | 级数 | 成本 | 星门槛 |
|---|---|---:|---|---|
| 伤害 | 炮弹伤害 +8% | 4 | 12 / 28 / 60 / 120 | 0 / 0 / 12 / 20 |
| 炮台数 | 多一门炮（2→4） | 2 | 60 / 200 | 8 / 第二章开放 |
| 射速 | 开火间隔 −4% | 3 | 16 / 40 / 90 | 0 / 0 / 16 |
| 开局金币 | +2 | 3 | 14 / 32 / 70 | 0 / 0 / 16 |
| 基地生命 | +1（3→5） | 2 | 50 / 160 | 10 / 22 |

前三级刻意便宜（12 / 14 / 16），保证头几关就能点到 2、3 次。贵的那几级靠总星门槛卡住，让人想着往后打而不是原地刷。

炮台数 Lv2 的门槛设成 99 星（超出本章上限 24），`CanBuyForge` 检测到门槛超上限时改显示 `LockNote`，也就是「第二章开放」。这吃掉了原来白给的 `GameConstants.MaxEmitters = 4`。

**接线方式**：`ForgeCatalog.Stats` 把等级折算成 `ForgeStats`，`BattleWorld.Begin` 只认这个结构，不认等级。伤害和射速落成两个系数 `_damageMul` / `_intervalMul`。

伤害升级抬的是 `ShotMods.BaseDamage`，**不动加算池和乘算池**，免得和「镇金」那条招牌抢规则（见 [字效管线.md](字效管线.md)）。

## 技能（6 个，局外装 2 个）

共享一条**能量**条 0–100，开局 0，击杀按敌人金币值 ×2 累积（`EnergyPerGold`）。

| 敌 | 金币 | 能量 |
|---|---:|---:|
| Swarm | 1 | 2 |
| Walker / Runner | 2 | 4 |
| Strafer | 3 | 6 |
| Shield | 4 | 8 |
| Elite | 8 | 16 |
| Boss | 14 | 28 |

共享条而非各自 CD，两个键天然抢资源，才有「攒大招还是先放小招」的取舍。

| 技能 | 能量 | 效果 | 解锁价 | 门槛 |
|---|---:|---|---:|---|
| 墨爆 | 25 | 最前排敌人处半径 1.2 炸开，6 伤 | 0 | 初始 |
| 定身 | 35 | 全场定身 1.6s（复用 `StatusKind.Stun`） | 40 | — |
| 强攻 | 45 | 5s 内炮弹基础伤害 ×2 | 75 | — |
| 横扫 | 55 | 全屏 5 伤 + 纵向击退 0.9 | 120 | ★14 |
| 泼墨 | 50 | 敌人最多那一列 3s 灼烧 3/s（复用 `Burn`） | 160 | ★18 |
| 回血 | 70 | 基地 +1 血，每局限一次 | 220 | 通关本章 |

**只做解锁与装备两态，不做技能等级**，控制 UI 复杂度。

技能效果**不走 `ResolveHit` 的十步**，各自直接改血/状态（`BattleSpells.SpellHit`），免得域里再套域、免得触发斩杀和连斩。强攻走 `RageTime`，在 `FireBullet` 里抬 `BaseDamage`，和局外伤害升级同一个口子。

装备是点一下切换：已装备的取下，没装备的填第一个空槽，两槽都满就顶掉第二格。取下第一格时第二格会顶上来，避免出现「空槽在前、有技能在后」。

## 广告位（4 个）

| slot | 场景 | 限制 |
|---|---|---|
| `reroll` | 改装三选一「看广告重刷」 | 每次 draft 1 次 |
| `revive` | 失败结算「续命」 | 每关 2 次 |
| `double` | 通关结算「墨翻倍」 | 每次结算 1 次 |
| `stamina` | 出征页体力不足时「+6 体力」 | 每日 5 次 |

主力是 `stamina`。全部走 `AdStub.Reward(slot, onOk)`，目前是立即成功的 stub。

## 存档

key `inkline.meta.v2`，`JsonUtility` 序列化整个 `MetaProgress`。

读不到 v2 时回落读 v1 的管道字符串并迁移：`ChapterCleared` → 炮台数 Lv1，`StartGoldBonus` → 开局金币 Lv1，并按已有总星补发 `总星 × 4` 墨，免得老存档进来面对空的升级树。

`Normalize()` 每次加载都跑，负责把数组补齐到当前长度、把等级夹回上限、保证 0 号皮肤和 0 号技能永远持有、清掉指向未持有技能的装备槽。**加字段只要改 `Fit` 调用那几行，不用动 key**。

## 明确不做

不做每日签到、不做转盘抽奖、不做付费货币、不做体力购买弹窗、不做技能等级。皮肤零数值。
