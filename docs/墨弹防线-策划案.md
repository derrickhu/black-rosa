# 《墨弹防线》策划案

> 版本：MVP v0.1 | 日期：2026-09-05 | 项目：`black-rosa`

一句话：**单指滑动发射器，子弹自下而上穿过格子里的改装件，一列效果按穿过顺序叠加；击杀掉落金币，金币够了随时三选一（不跟波次绑定）；同牌可铺开或叠星；关卡用波次只做出怪节奏，局外解锁改装与发射器。**

本文是玩法唯一来源。实现以第一章竖切验证循环为准。

---

## 1. 可行性结论

玩法成立，而且比「再做一个植物大战僵尸」更适合做新品。操作是超休闲（一根手指左右滑），决策是轻策略（往哪列开火、格子怎么叠），爽感来自子弹变彩和击破反馈。用团结引擎做 2D 弹道/叠加特效，比继续用 Pixi 更合适。

品类定位：

- 外壳：保卫萝卜 / 植物大战僵尸式的「上路敌人、下路我方、分列」
- 内核：弓箭传说 / 弹壳特攻队的「三选一」+ Magicraft / 以撒式的「弹道改装顺序」
- 操作：Ball Blast / 大炮打砖块式的底栏炮台
- 视觉钩子：全场先黑白，改装给子弹上色。商店封面必须用「中局已上色」的图。

变现：微信 IAA。一关约 2～2.5 分钟。四个激励位：失败续命、商店重刷、结算墨翻倍、体力不足补体力（主力）。不做无尽生存当主模式。

---

## 2. 对标差异

- **植物大战僵尸 / 保卫萝卜**：格子不种会开火的植物，只改装已经在飞的子弹。
- **弓箭传说 / 弹壳特攻队**：他们清完一波才三选一。我们用金币门槛，打着就能加装。
- **随机骰子 / 自走棋升星**：我们不做三合一自动合成。抽到同牌时，玩家自己决定铺开还是叠星。
- **Magicraft / 以撒**：弹道插件顺序即 Combo。做成看得见的 3 层管道。

---

## 3. 核心循环

```
进入关卡 → 持续战斗（波次只出怪）
  → 滑动炮串选列 → 子弹穿过列上改装 → 击杀掉金币
  → 金币够了点「改装」短暂停三选一
  → 点空格铺开或点同牌升星 → 立刻继续打
  → 敌人撞底线扣血 / 关底头目 → 结算
```

### 必须避开的坑

1. **空列**：敌人必须向下走；炮串相邻平移；前几关池子里要有分化/穿透/爆炸。
2. **棋盘填满**：先只开最底层；同牌可升星，异类覆盖；一关结束清盘。
3. **商店绑波次**：不绑。频率只调掉落和抽牌价。

---

## 4. 已拍板规则

- 列数：**6 列 × 3 层**（`GameConstants.Columns`），代码用常量，以后可加列。
- 三选一：金币够了点按钮、短暂停、不绑波次。商店永远只出 **1 星**。
- 星级：上限 **3 星**。点同名未满星格 +1 星（1→2→3）。
- 数值：2 星约 1.7～1.9 倍，3 星约 2.6～3.0 倍，铺开覆盖优于线性加倍。
- 发射器：开局 2 门，固定相邻，整串平移，松手吸附列中心。局内最多 4 门。
- 抽牌价：4 / 6 / 8 / 10…（每次 +2）。开局 6 金，进关就能抽第一张。前两关前 3 次够金自动弹出。
- 基地血：3。广告续命每关最多 2 次。

### 改装牌（一字一牌）

- **常驻无 CD**：火、冰、分、瞄、速，以及后续章节的金、木、水、土、风、雷、毒、惑。过格就改弹，可叠。
- **常驻有 CD**（过 2 发，第 3 发触发）：穿、炸、重、晕。
- **词组字**（单放沉睡，同列凑齐才醒）：秒+杀、万+箭、击+退、连+斩。成词后同列常驻仍可叠。词用更长弹数充能（秒杀 3 蓄第 4 发）。

没有炮牌。只改穿过该列的子弹。未成词的字占格但不改弹。

Combo：**先分再火 = 多发火弹；秒杀+火 = 平时火弹，第 4 发火斩。**

**结算骨架**：所有命中（直击 / 溅射 / 连斩 / 落箭）都走同一条十步顺序，
`盾 → 斩杀 → 基础伤×道族衰减 → 加算 → 乘算 → 吸血 → 扣血 → 状 → 位 → 域`。
六条叠加规则里最要紧的三条：加算不吃乘算（留给「镇金」）；硬控 `冻 > 晕 > 惑` 同时只生效一个，输的降级成等时长的缓；域伤害不再触发域。
26 个字的完整数值、五个表现槽位、12 对招牌两两，全在 **[`docs/字效管线.md`](字效管线.md)**，那份是唯一数值来源。

**新元素按章解锁**（`StageCatalog.ChapterUnlocks`），每章最多进两个新家族：
二章金+雷（加伤 + 范围控）、三章木+毒（吸血 + 可叠层 DoT）、四章水+土（范围缓 + 上推）、五章风+惑（横移 + 反打）。
第一章仍然只有底盘 18 字，不让三行被元素挤满。

### 敌人

步兵、快跑、盾兵、团子、横移 + 关底（二阶段上色）。

### 第一章

8 关，每关连续战斗、8 段出怪 + 关底。

- 1～2 关：只开第 1 层，池子分化/火/冰。第 1 关第一次够金强制教抽牌。第 2 关第一次重复牌教升星。
- 3～5 关：开第 2 层，加入追踪/穿透/爆炸。
- 6～8 关：开第 3 层，加入加速/重击和上色精英。
- 通关星：**按丢血量算** —— 丢 ≤1 血 3 星、丢更多 2 星、续命通关 1 星。3 血时和旧规则等价，但局外加基地血之后不会自动放水。

## 4.5 局外成长

完整数值见 [`docs/局外成长.md`](局外成长.md)，那份是唯一真相。这里只钉边界。

- 局内金币抽改装牌**不变**；局外拿的是另一种货币「**墨**」，通关结算发。
- 局外只动两样：**开局条件**（伤害 / 炮台数 / 射速 / 开局金币 / 基地生命，5 条线）和**一局内的应急手段**（6 个技能，局外装 2 个）。
- 局外**绝不**解锁或强化字牌。章节元素解锁继续按章免费放，不卖。皮肤零数值。
- **体力**封住墨的产出速度：上限 12，重刷一关 2 点，每 15 分钟回 1。**没通过的关不收体力**，推主线全程免费。只有通关才真的扣。
- 技能靠击杀攒**能量**（共享一条 0–100），战斗中点右下角两个键释放。技能不走十步结算，各自直接改血/状态。
- 新手礼包：首次进入满体力 + 60 墨 + 第一章首通免体力。日活钩子只用「每日首胜」，不做签到。
- 广告位 4 个：`reroll` 重刷、`revive` 续命、`double` 墨翻倍、`stamina` 补体力。主力是 `stamina`。

## 5. 美术

白纸底、黑墨线。颜色只出现在改装、被改过的子弹、灼烧/冰/爆、显形、精英/关底、后期彩炮。布局用代码写。

字效表现分四类，规格见 [`docs/字效管线.md`](字效管线.md) 第 4 节：炮弹五槽（体/尾/环/绕/晕光）、命中三层（墨溅底 + 单一元素层 + 事件印章）、敌人身上的六种 DoT 标记、抽卡字面。
两两三三不画专图，靠层叠出新鲜感；只有 12 对招牌两两换一张「体」槽图。

贴图预算：磁盘 6.0 MB、运行时 35.6 MB。`Resources/` 是整包打进去的，不要往里丢没有代码引用的实验素材。

## 6. 工程架构（MVP）

团结引擎 `2022.3.62t8`。运行时创建战场和 UI，场景里只有相机。

```
Assets/Scripts/
  Core/      入口、流程、局外存档、常量
  Data/      牌/敌人/关卡表
  Battle/    纯逻辑：棋盘、弹道、敌人、波次、经济
  View/      墨线几何体、战场同步
  UI/        首页（三段底栏）、HUD、三选一、放置、结算
  Platform/  广告接口（先空实现）
```

- `GameConstants.Columns` 是列数唯一来源。
- `BattleWorld` 不依赖 UI；暂停只冻模拟，不冻选牌。
- 子弹穿过格子时按当前 X 所在列、从下层往上依次生效。
- 微信导出和激励视频留到循环验证之后。

验证标准：

1. 15 秒内会滑炮去对准有改装的列。
2. 前 20 秒内打出第一次变色弹，一关里构筑会变多次。

4. 第二张同牌时，铺开和叠星都合理。
