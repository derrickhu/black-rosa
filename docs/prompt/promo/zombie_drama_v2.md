## 人物

信息流爆款短剧那一对：**冷面战神**听**清冷飒姐**的。好看、干净、衣服完好，废墟只是背景。前 3 秒先给出正脸。

- **陆沉**（冷面战神）：二十七八岁。窄脸，眉骨高，眼窝深，薄唇，冷白皮。黑色纹理短发，额前落一缕。黑色修身衬衫，领口解开一颗，炭黑色长大衣敞着。话少，声线低，不开玩笑。点炮像在办事。
- **苏晚**（清冷飒姐）：二十三四岁。鹅蛋脸，眉形干净，眼尾微挑，唇是正红口红那种红。黑色长直发披在肩前。黑色修身短外套，里面一条香槟那种浅金的缎面吊带，锁骨露出来，黑长靴。她发号施令，他照做。

两个人都不戴头带，不穿黄风衣，头发上不别毛笔。

## 场景

傍晚，城市废墟里一座三层骑楼的平顶天台：沙袋矮墙，黑铁老炮（木轮、铜箍），旁边一堆黑铁炮弹。夕阳橘红，天上烟尘。

楼下三条巷子汇到炮口正下方，每条巷子一列僵尸往楼上涌。灰脸、破衣服，喜剧恐怖片妆，不见血。领头三只已经扒上沙袋。

## 生图 / 图生要点

- 首帧先保证脸好看、五官清楚，景别靠近脸。男主冷白皮、窄脸、高眉骨；女主鹅蛋脸、正红唇、黑长直。
- 男主大衣是炭黑，衬衫是黑的。女主外套是黑的，吊带是香槟那种浅金，唇是正红口红那种红。
- 「分」是墨黑书法，外圈一圈月光那种银白辉光，两撇末梢像小刀。
- 「击」和「退」都是铜钱那种黄的书法，上下对齐，间距固定。「退」底下自带一道小黑箭。
- 有字的镜头（2、3、4、5）写 static locked-off camera，字在首帧里的位置全程不动。
- 台词每镜最多两句短句，中文原文加引号。声线：他低、她慢。
- 裂开的三颗弹都还是原来那种黑铁圆弹，只是飞行方向岔开，不换火球、不换冰晶。
- 实机尾板用真录像，录「分」裂弹和「击」「退」同列击退，各大约一秒。
