# 墨字防线 · 微信转发图

用途：`wx.shareAppMessage` 聊天卡片。母版进  
`game_assets/black-rosa/推广/转发图/`  
不要写进游戏仓库，等确认。

规格：先出 4:3 母版，再 cover 裁成 **5:4**，成品 **500×400 JPG**。  
上方留一条干净纸面，标题用系统字体后叠，模型不写标题。  
牌上只允许参考图里的「火 / 冰 / 炸」，不要别的汉字、英文、数字、水印、按钮。

## s1 子弹认字

暖宣纸、祥云。正中一列三张宣纸牌，上冰、中炸、下火。下沿墨炮仰射，橙弹穿过这列后尾迹变彩虹。上方 1/4 留空给标题「这三个字，子弹比你熟」。

## s2 黑进彩出

左半纸面全黑白：石墨墨线人和灰弹。右半同一发弹穿过「火」牌后炸成橙焰和彩屑。中间是那张火牌。上方留空给「黑的进去，彩的出来」。

## s3 种汉字

墨线人从上方压下来，中线横着三张牌挡住：火、冰、炸。下沿一门墨炮。不要植物、不要花。上方留空给「不种花，种汉字」。

## s4 同字叠满

同一列三张「火」由小到大叠成塔，最上一张带彩屑。炮从下打穿整列。上方留空给「同字叠满，这列封神」。
