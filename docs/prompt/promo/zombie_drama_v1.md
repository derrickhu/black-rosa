# 墨字防线 · 真人短剧买量片 v1「末日炮台」

竖版 9:16，约 28 秒。Vidu q3-turbo 图生视频（音画同出），首帧用内置生图出 35mm 电影剧照。
冰、火两个字不让模型画：用游戏里的 `heap_ice.png` / `heap_fire.png` 抠出来加辉光，合进首帧再图生。
成片、首帧、原片都在 `game_assets/black-rosa/推广/宣传视频/drama_01/`，不进仓库。

## 人物

- **阿强**：二十八九岁，瘦高，乱发箍一条红色运动头带，芥末黄风衣，工装裤。慌、碎嘴，负责搞笑。
- **小墨**：二十五六岁，高马尾用一支毛笔别住，黑色立领盘扣短外套，深色工装裤。冷脸，懂字。

## 场景

傍晚，城市废墟，三层骑楼的平顶天台，沙袋垒成矮墙，一门黑铁老炮（木轮、铜箍），旁边一堆黑铁炮弹。
楼下整条街都是僵尸，灰脸、破衣服，喜剧恐怖片那种妆，不见血。天上烟尘，夕阳橘红。

## 生图 / 图生要点

- 首帧只写正面要求，颜色用实物锚定：头带「红领巾那种红」，风衣「芥末酱那种黄」，冰字辉光「冰川那种蓝」，火字辉光「炭火那种橙」。
- 字留在固定机位镜头里（2、3、4、5），提示词写 static locked-off camera，字不容易跑形。
- 台词每镜最多两句短句，中文原文加引号。说不出声的镜头改走参考生 + voice_id。
- 字幕、Logo、按钮后期用真实字体叠，模型不画字。
