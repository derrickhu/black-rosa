# 墨字防线 · 微信转发图 v3

聊天卡片。先出 4:3 母版，再 cover 裁成 5:4，成品 500×400 和 1000×800 JPG。
母版放 `game_assets/black-rosa/推广/转发图/v3/`，确认前不进游戏仓库。

图里不写口号。字只出现在字牌上。画法跟已过审的转发图同一支笔：酱油色粗描边、平涂、墨人两只白豆眼、木炮。

缩略图要在聊天列表里一眼分开，并且要比实机夸张。可以借代，不用照着棋盘画。

## c3 字牌决口

一块铺满画面的「火」字牌当堤坝，从中间裂开，黑墨连着墨人从裂缝里涌出来。底部只有一门玩具大小的木炮顶着。

## c5 表情包贴脸

借抓大鹅、羊了个羊：转发图本身就是一张能当表情包发的脸。红底，墨人大哭，头顶一门小炮。

## c6 左右你哭我笑

借聊天里最常见的对比卡：同一张脸，左边守崩了，右边戴冠坐在方孔金币上。

## c4 字就是炸弹

「炸」这个字本身裂开，笔画缝里喷出方孔金币和红包色的火。底部一门小炮只是引线。

## c1 黑潮贴脸

配「救救我！防线告急」。人潮占画面上方大半，贴到镜头前；底部只有两门小木炮，中间一排「火」牌。草地是新茶叶那种绿。

## c2 巨字爆金

配「一炮清屏」这种好奇。正中一块几乎铺满画面的「炸」字牌，牌上沿爆出金币和红包色的火焰，牌下只有一门木炮朝上打。地面是沙滩那种暖沙。
