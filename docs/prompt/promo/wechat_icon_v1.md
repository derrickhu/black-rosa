# 墨字防线 · 微信小游戏图标

只用 Cursor `GenerateImage`，1:1。母版和成品进  
`game_assets/black-rosa/推广/微信头像/`  
不要写进游戏仓库，等确认。

规格：正方形铺满，主体落在中央 70% 圆安全区（微信会圆裁）。  
图内不要标题、数字、水印、商店徽章、白边、透明边、外框截图。  
允许一个设计过的汉字当图形主体（火 / 防 / 墨），那是图标本身，不是字标。

## v1 汉字牌火

赵云与阿斗那种：宣纸方卡铺满视野，正中一个「火」，黑字，两点是橙焰。卡芯 `#FCFCF6`。不要再套一层 App 圆框。

## v2 防字墨印

正中一个魏碑「防」，黑墨实心。底是暖宣纸，四角淡墨晕。像印章，不是牌。

## v3 炮打出彩

略俯视短墨炮在下沿，一发橙弹穿过正中「火」字牌，弹尾变彩。背景纸白到浅墨。炮和字都在安全圆里。

## v4 黑白变彩

左半纸上石墨「火」，右半同一笔燃成橙焰和彩屑。中间一条亮色弹道。不要写成两个字。

## v5 墨线人+字牌

圆头墨线小人在下，正中大「火」字牌，像休闲头像。背景青绿或纸青，对比较强。不要写标题。

## v6 墨字徽

正中一个很大的「墨」，黑，边缘干净。右下角一小舌橙焰长进一点。底色深墨或暖纸，保证缩到 144 还能认。

## v7 墨线人大头（参考 srpg 头像）

青绿实底，正中一个圆头墨线人胸像，头占安全圆。不要字、不要花、不要标题。

## v8 字牌簇（参考菜猪头像）

正中叠三张宣纸牌：火、冰、炸。后有黄光圈，外圈深青。只能出现这三个字，笔画必须对。

## v9 防线横截面（参考我的防线 / PVZ）

中线两张「火」字牌挡路，上沿两个墨线人，下沿一门墨炮打出彩弹。纸底铺满。不要标题。

## v10 商店休闲火牌（参考花花青绿底）

青绿底 + 一张很大的「火」字牌居中。不要圆遮罩、不要标题、不要乱字。

## v11 炮打字牌簇（v3 场面 + v8 多牌）

图一的暖纸、祥云、下沿墨炮、橙弹出彩；把正中单张「火」换成图二那种三张叠牌：前「火」、左后「冰」、右后「炸」。炮打前牌。只能这三个字，笔画必须对。不要青绿底，不要标题。
