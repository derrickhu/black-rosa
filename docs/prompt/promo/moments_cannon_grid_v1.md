# 朋友圈九宫格 · 炮台贴纸 v1

九张 1:1。前七门是游戏里已有的皮肤，后两门是同一套贴纸画法新画的。九宫格从左到右、从上到下按编号排。

画法锁游戏炮台：平涂色块、两层硬边明暗、小白高光、深酱油色粗描边、奶油色贴纸边、圆滚滚玩具比例、四分之三侧视、炮管朝右上。底是没染色的宣纸暖米白，铺满四边。画面里只有这一门炮。

母版和成品在仓库外 `game_assets/black-rosa/推广/朋友圈/cannon_grid_v1/`。后台方图只收 800×800，上传用 `final/*_800.jpg`（JPG）。

墨笔：竹黄笔杆当炮管，笔锋围成炮口，砚台当炮座。
青竹：新竹筒当炮管，五根竹段捆成炮座。
