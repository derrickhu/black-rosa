# 汉字牌零件 · 第十版（可合成）

只用 Cursor `GenerateImage`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_v10/`  
炮弹特效不要动。

不再一次生成「字+效果」。零件分开：
- **完整字**：只有黑字，没有饰
- **饰图**：只有效果小图，没有字

合成、挪笔画、叠加在 Unity「墨弹防线 / 汉字牌合成」里做。

## 合成窗怎么用

1. 菜单打开「墨弹防线 / 汉字牌合成」
2. 选牌，会自动载入 `Art/hanzi/char_火.png`（没有就用 `font_火`）
3. 「加本牌饰图」叠上对应小图
4. **框选拆笔**：圈住要挪/删的笔画，松开后变成新层，可拖、横拉/纵拉、旋转、翻转、删除
5. **橡皮**：在选中层上擦；⌘Z / 撤销可退回
6. 「导出到 heap_xx」只写出字和饰（透明底，不带卡框）。宣纸方卡由游戏统一套

## 字

白底，一个黑字，实心、边缘闭合。不要卡框、不要饰、不要星数字英文。

火 冰 分 瞄 穿 炸 速 重

## 饰

白底，一个实心小图，边缘闭合。不要字、不要卡框。
