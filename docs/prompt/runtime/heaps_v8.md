# 格子改装 · 第八版（图饰汉字）

只用 Cursor `GenerateImage`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_v8/`  
炮弹特效不要动。

上一版只是把笔画换了色，太保守。本版：**用图装饰字，或用图代替某几笔**。
字身保持全黑。不要泼墨飞白，边缘仍要完整。

## 风格锁

宣纸方卡铺满 1:1，圆角，卡芯 `#FCFCF6`，双线石墨框。正中一个黑字，约占 60%。

- 字身 `#1A1410`，实心、边缘闭合。**禁止把某一笔改成别的颜色来当效果。**
- 效果必须是**能认出来的小图**：火是火苗形，加速是人字标，爆炸是爆开的团。可以挂在字下，或替掉某几笔。
- 小图也是实心、干净边，不要飞白、泼墨、毛边。
- 平面，不要 3D，不要发光。不要星、数字、英文、第二字、水印。
