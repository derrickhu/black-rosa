# 格子改装 · 第六版（汉字牌）

对比过 Cursor `GenerateImage` 和 Gemini NB2。这轮汉字牌 **Cursor 胜**：字身能保持黑墨，效果贴在笔画上。Gemini 更容易整字染色、做立体撕纸，还会写错字或加扑克数字。

狂墨提示词见 `heaps_v6b/`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_v6/{cursor,gemini,pick}/`  
炮弹特效不要动。不要墨滴、不要立体堆、不要动画。

参考《赵云与阿斗》《悟空与唐僧》：格子上的单位就是**一个一看就懂的汉字**。
字是黑的；效果只做笔画变形 / 一小撮点缀。后续同列多字可组合（本版不实现玩法）。

## 统一语言（已锁）

- **主语永远是一个汉字**，不是物品、不是几何符、不是墨滴。
- 八张共用同一张宣纸方卡：圆角、卡芯 `#FCFCF6`、双线石墨框 `#2E2E2E`。
- 正中一个大字，约占卡面 70%。字体：魏碑 / 厚墨楷，黑色 `#1A1410`。
- **点缀只改笔画或贴着字的一小撮**，色值跟穿过后的炮弹走。不要整字染色，不要发光，不要 3D。
- 不要星、数字、英文、第二字、水印。

禁止：墨滴、炮塔、矛、纯几何箭头、整卡铺色、渐变字、描边发光。

## 后续（先记下，本版不做）

同列相邻字可拼更强效果，例如：火+炸、冰+重、分+穿、瞄+速。
卡面必须先能单字读懂，组合才加得上。
