# 格子改装 · 第九版（笔势融合）

只用 Cursor `GenerateImage`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_v9/`  
炮弹特效不要动。

参考《赵云与阿斗》截图：「枪」的矛尖是**写出来的一笔**，不是旁边贴了一个图标。
上一版字太正、标志太死板。本版：字要有笔势，标志必须长进笔画里。

## 风格锁

宣纸方卡铺满 1:1，圆角，卡芯 `#FCFCF6`，双线石墨框。

- 字是**手写笔势**：粗细差、略倾、有甩笔，像截图里的枪/弓/骑。不要端正电脑字。
- 效果图和字是**同一笔写成的**：火舌就是「火」的两点，人字标就是「辶」甩出去的尾，爆炸从「火」旁炸开。禁止字下一个独立贴纸。
- 边缘仍要**闭合干净**，不要泼墨飞白、毛边、半透明拖尾。
- 字身黑 `#1A1410`。色只在融进去的那几笔效果上。
- 平面，不要 3D 浮雕，不要发光描边。不要星、数字、英文、第二字、水印。
