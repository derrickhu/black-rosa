# 速 / 重 · 第十一版（字不能改结构）

只用 Cursor `GenerateImage`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_v11/`  
炮弹特效不要动。

上一版把「速」「重」的笔画改没了：辶变成翅膀，重底下多出两只爪。  
本版：**字必须还能认**。效果只长在某一笔的末梢，不改笔画数量，不改字形。

参考「冰」：水旁还是水，只有「冫」写成冰晶。  
参考「火」：人字还在，只有两点写成火。

## 锁

- 1:1，卡芯 `#FCFCF6`。**不要卡框、不要圆角双线、不要星数字英文。**
- 字身黑 `#1A1410`，实心，边缘闭合。手写笔势可以有，但不能少笔、加笔、改部首。
- 平面。不要泼墨飞白。

## 速

完整「速」：右边「束」齐全（一、口、竖、两撇捺），左边「辶」齐全（点、横折、长捺托住束）。  
禁止把辶改成翅膀、刀锋、飞羽、残影。  
两个人字标（深绿 `#2E7D4F`）只从辶长捺的**右尖**长出去，叠在末梢，像甩笔带出来的加速尾。

## 重

完整「重」：撇、横、千里结构，底下一笔是**一根长横**。  
禁止在字下面加锤、爪、钩、腿。禁止后期贴块、白线打叉。  
只用 AI 一次写成。只在中间「田」里变形：田仍是田，但被压沉、写得更密更重，和上下笔是同一口墨。其它笔画不动。
