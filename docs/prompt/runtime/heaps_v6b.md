# 格子改装 · 第六版 b（狂墨汉字）

上一版点缀太小，看起来像程序描字。本版：**底稿只认字，AI 必须重写成活的墨**。
炮弹特效不要动。

对比：Cursor `GenerateImage` vs Gemini NB2。谁更有笔墨和差异感，谁入库。

母版：`game_assets/black-rosa/美术/runtime/heaps_v6/{cursor,gemini,pick}/`

## 风格锁

宣纸方卡铺满 1:1，圆角，卡芯 `#FCFCF6`，双线石墨框。正中**一个**黑字，约占 65%。

- 参考只告诉你这是哪个字。**不要描字体、不要电脑字、不要描边均匀的黑体。**
- 必须重写成湿墨狂草 / 魏碑泼墨：飞白、涨墨、飞溅、笔画粗细差很大。
- **战斗效果必须占卡面大约三分之一**，88px 缩略也能一眼看出火/冰/裂/瞄/穿/炸/快/沉。
- 字身仍是黑 `#1A1410`。点缀色只染在效果上，对上炮弹色。
- 平面墨，不要 3D 浮雕，不要整字渐变，不要发光描边。
- 不要星、数字、英文、第二字、水印、物品模型。
