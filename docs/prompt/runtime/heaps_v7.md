# 格子改装 · 第七版（干净字牌）

只用 Cursor `GenerateImage`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_v7/`  
炮弹特效不要动。

参考《赵云与阿斗》截图：白方块 + **边缘完整的实心黑字**。
上一版泼墨飞白在 88px 会脏，也不好抠。本版禁止溅墨。

## 风格锁

宣纸方卡铺满 1:1，圆角，卡芯 `#FCFCF6`，双线石墨框。正中一个黑字，约占 70%。

- 笔画**实心、边缘闭合、轮廓干净**。像截图里的「枪 / 弓 / 刀」：楷意毛笔，但边是齐的。
- **不要**飞白、泼墨、水花、颗粒、毛边、半透明拖尾、纸纹脏点。
- 效果是**一小块实心变形**长在某一笔上（截图「枪」的矛尖那种），不是喷一圈特效。
- 字身 `#1A1410`。点缀色只染在那一小块效果上。
- 平面，不要 3D，不要发光。不要星、数字、英文、第二字、水印。
