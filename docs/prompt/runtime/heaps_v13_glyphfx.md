# 汉字牌 · 带字效的统一字图（v13）

v12 是纯黑书法，每个字没有个性。v13 把元素意象**融进笔画**，做法对齐微信图标里的 冰 / 火 / 炸。

只用 Cursor `GenerateImage`。母版 `art_src/heaps_v13/`，入库 `Assets/Resources/Art/heap_<key>.png`。
运行时由 `InkArt.OnCard` 套宣纸框，并按墨迹包围盒缩放到卡芯 64%。

## 核心规则（这条是承重墙）

**字身 90% 保持黑墨手写，只把「一个指定的小笔画」换成该字的元素意象并上色。骨架一笔不动。**

为什么这么定：
- 只改点、短撇、末笔这类小笔画，不碰主干，**不会写错字**。25 个字都能用同一条规则，风格自然一致。
- 颜色只出现在那一处，卡面整体仍是黑白宣纸，不会和「颜色只给改装过的东西」这条美术底线打架。
- 加字时只要回答「换哪一笔、换成什么、什么色」三个问题。

两套配色，一眼分得出牌的类别：

| 类别 | 字身 | 意象 |
|---|---|---|
| 常驻字（含蓄力） | 墨黑 `#1A1410` | 该元素的主色 |
| 词组字（要凑齐才醒） | 金 `#E8B43A` | 墨黑 `#1A1410` |

道族三字（分 / 穿 / 重）没有专属色，意象用石墨 `#6A6A6A`，靠形状区分而不是靠颜色。

## 渲染约束（踩过的坑）

生图容易把意象画成**写实宝石 / 3D 玻璃 / 贴上去的 clipart**，和笔触完全两路。提示词里必须硬写：

```
CRITICAL RENDERING CONSTRAINT — flat, hand-painted, two-tone shape in the same
illustration language as the brush strokes. Absolutely NOT photorealistic,
NOT a 3D gemstone, NOT glossy, NOT gradient-rendered, NOT pasted clipart.
Same size as the stroke it replaces, tucked in the correct position,
still reading as that stroke.
```

另外三条硬规矩，每条都是返过工才补上的：

1. 意象**不得放大**、**不得飘离字身**，否则读起来像字旁边摆了个图标。
2. 意象**不得形成独立闭合形状**。万原本用「钩的多重残影」表示「多」，结果右下角那团墨读成了一个「刀」字，整张变成两个字。改成让长撇末端**分股散开成细丝**，丝始终贴在笔画上、不闭合，才解决。
3. 意象**不得把外接框撑出去**。穿的针尖、速的速度线都干过这事 —— 撑宽了框，归一化就会把字本体压小。要么收进字块轮廓内，要么靠下面的墨量归一化补偿。

字形本身也常翻车：瞄生成成了「眼」、杀生成成了「分」。所以每个字的提示词都要**逐笔描述结构**并**列出禁止的形近字**，光写一个字是不够的。

## 画布

1:1，浅纸白 `#FCFCF6` 铺满。不要卡框、圆角、双线、星、数字、英文、水印、印章。
正中一个简体字，四边留白相等，任何一笔不贴边。
手写厚墨、实心、边缘闭合、略有笔势。不要电脑黑体、不要魏碑、不要飞白、不要立体阴影。

## 归一化：按墨量，不按外接框

生完跑 `docs/prompt/runtime/heaps_v13_normalize.py`，母版在 `art_src/heaps_v13/`，输出直接进 `Assets/Resources/Art/`：

```
python3 docs/prompt/runtime/heaps_v13_normalize.py art_src/heaps_v13 -o Assets/Resources/Art --size 256
```

v12 的做法是把每个字的墨迹外接框缩到画布 58%。**这个度量是错的**，两头都不准：

- 瞄这种左右结构把框填得几乎全满，墨量 12.4%，看起来比别的字重一大截；
- 速的绿色速度线把框往左撑宽，字本体反而被压小（墨量只有 7.4%）。

v13 改成：先按 58% 框把字放好，**再按墨量往共同目标（9.6%）修正一次**，面积随缩放平方变化所以修正量开平方，并夹在 0.82~1.18 之间、外接框最终仍限制在 50%~66%。这样瞄自动缩到 0.88 倍、速放到 1.14 倍，整套的视觉轻重就齐了。

加字不需要手调，跑脚本即可。
