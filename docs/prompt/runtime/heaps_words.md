# 词组字 / 晕 · 汉字牌

只用 Cursor `GenerateImage`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_words/`  
字图**不带卡框**，框由游戏 `InkArt.OnCard` 套。参考运行时 `heap_heavy.png` / `heap_fire.png`。

和火、瞄、重同一套手写墨字：粗细差、略倾、实心、边缘闭合。不要魏碑电脑字，不要泼墨飞白。  
底稿只用来认字，不能改笔画、加笔、少笔、改部首。

- 1:1，浅纸白 `#FCFCF6` 铺满。不要卡框、不要圆角双线、不要星数字英文水印。
- 正中一个字，约占 60%。
- **晕**（常驻、要蓄）：字身黑 `#1A1410`，和火/重同一套。
- **词组字**（单放要等）：整字黄 `#E8B43A`，笔画结构仍跟黑字那套一样，只换颜色。
