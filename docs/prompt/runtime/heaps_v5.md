# 格子改装 · 第五版（墨滴变体）

只用 Cursor `GenerateImage`。母版进  
`game_assets/black-rosa/美术/runtime/heaps_v5/`  
炮弹特效不要动。不要立体炮塔/冰墙/矛，不要纯几何符号。

## 统一语言（已锁）

参考《以撒的结合》眼泪变体：同一颗弹，换一层效果。

- **主语永远是同一颗石墨墨滴**（默认弹）。大小、描边、位置八张一致。
- **谓语是这张牌对它做的事**（裂、燃、冻、拐、穿、炸、快、沉）。
- **点缀色只染在滴上或紧贴滴的一小撮效果**，色值跟 `InkTheme` / 对应炮弹走。卡纸和框仍是宣纸+石墨。
- 平面、2 档平涂、近黑描边。不要 3D，不要第二套物品。

禁止：单独的 Y 箭、单独的人字、单独的八芒、单独的矛、单独的炮塔。没有墨滴就不算这套语言。

## 卡框

方卡铺满，圆角。卡芯 `#FCFCF6`。双线石墨框 `#2E2E2E`。不要字、星、数字。
