三门塔防手游里的迫击炮台贴纸，横着排成一行，均匀散放在一整片纯品红 #FF00FF 背景上，每门炮之间隔着大片品红空地。画法和参考图里的小炮完全一致：休闲卡通、深酱油色粗描边、外圈一道细细的奶油色纸边、两层硬边明暗、几处小白高光、圆滚滚的胖比例、玩具感。

每门都和参考图同样的迫击炮造型和视角：粗短的炮管斜着翘向右上方，炮座在下方，整体比宽度略高一点。三门大小一致、底边对齐。

左：糖果炮。炮管是圣诞拐杖糖那种红白螺旋条纹，炮口一圈草莓奶油那种粉色奶油花边，撒着彩色糖针；炮座是一只粉色礼物盒，系薄荷绿大蝴蝶结，两侧轮子是彩虹棒棒糖。

中：机甲炮。炮管是游泳池那种天蓝色的玩具机器人装甲，白色护板一节一节拼起来，炮口一圈发亮的荧光棒那种青色光环；炮座是一台短胖的小履带车，深灰橡胶履带，车身侧面一道柠檬那种黄的警示斜纹。

右：黄金炮。炮管是新金币那种明黄金，亮闪闪带白高光，炮身镶一颗草莓那种红的大宝石；炮座是一只打开盖子的海盗木宝箱，暖橡木色加铁皮包角，箱口溢出一堆金币。

画面里只有这三门炮和品红背景。
