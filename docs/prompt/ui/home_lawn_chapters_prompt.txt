第2章 土路（battle_bg_2）
台面是奶茶色的实心土路，有几块被踩浅的痕迹。左右边缘：小石子、嫩叶那种绿的小草丛、铅笔那种棕的短木栅栏柱、带浅色斑点的小棕蘑菇。正面厚度是更深一点的同一块土，嵌几颗小石子。

第3章 石院（battle_bg_3）
台面是燕麦饼干那种浅棕的大方砖，砖缝里有抹茶绿的细苔。左右边缘：小石灯、游泳池那种蓝的浅水洼、小小的盆栽。正面厚度是同一块浅石，底边更深一截。

第4章 沙漠（battle_bg_4）
台面是消化饼干那种浅棕的沙，有柔软的沙纹和几道干裂纹。左右边缘：青苹果那种绿的小圆仙人掌、混凝土那种灰的晒白石块、新硬币那种黄的小金块。正面厚度是更深的沙。

第5章 森林（battle_bg_5）
台面是开心果冰淇淋那种绿的软苔。左右边缘：柿子那种橙和香蕉皮那种黄的落叶、纸箱那种棕的小树桩、葡萄紫带白点的蘑菇、葡萄紫的小水洼、几株笋。正面厚度是可可粉那种深棕的土，嵌几颗石子。

第6章 河滩（battle_bg_6）
台面是蜜桃陶土那种浅橙的河岸泥。左右边缘：游泳池那种蓝的小水洼、平的灰踏脚石、芦苇丛和嫩叶那种绿的小稻秧。正面厚度是更深的湿泥。

第7章 雪原（battle_bg_7）
台面是糖粉那种白的雪，有天空蓝的淡影和被风吹出的雪纹。左右边缘：披雪的小松树丛、冰川那种淡蓝的冰晶、小雪堆。正面厚度是压实的雪，底边一条淡蓝的冰。

第8章 火山（battle_bg_8）
台面是芋头布丁那种灰紫的火山岩，有交通锥那种橙的细裂纹在发光。左右边缘：葡萄糖那种紫的小晶簇、碎石、深色小岩块。正面厚度是更深的灰紫岩，带一条细橙裂纹。

第9章 竹林（battle_bg_9）
台面是抹茶拿铁那种绿的软苔，中间空路是纸箱那种浅棕的实土。左右边缘：从上面看去的圆竹节，带着绿叶、落下的竹叶、光滑的灰石子。正面厚度是深一点的土。

第10章 古寺（battle_bg_10）
台面是河卵石那种暖灰的大方石板，缝里有细苔。左右边缘：石灯、陶盆里的小圆松、旧铜币那种青的香炉、香蕉皮那种黄的扇形银杏叶。正面厚度是同一块暖灰石，底边更深。

第11章 墨窟（battle_bg_11）
台面是饼干那种暖褐的大块平石，有更深的湿痕和细裂纹。左右边缘：灯光那种黄的小圆灯、奶油那种浅的尖晶簇、深色光滑石子、两三洼发亮的深色水。正面厚度是更深的洞窟岩。

第12章 地宫（battle_bg_12）
外框跟第一章一样高、一样厚。台面是米饼那种暖象牙色的长方石砖，缝是更深一点的沙色。中间空路只铺这种石砖。左右边缘：新铜钱那种黄的小圆碗、方石柱的柱顶、青瓷那种绿的扁圆片。正面厚度带和第一章一样高，颜色是同一块象牙色石，底边更深。

第13章 云海（battle_bg_13）
外框跟第一章一样高、一样厚。台面是淡天白色的大块软云砖，缝是浅蓝灰。中间空路只铺这种云砖。左右边缘：圆圆的小云团、新铜钱那种暖金的扁圆日轮、晴空那种蓝的小圆珠。正面厚度带和第一章一样高，颜色是牛奶盒那种淡蓝。

第14章 冥河（battle_bg_14）
外框跟第一章一样高、一样厚。台面是冷雾灰的长方石板，缝是更深的石板灰。中间空路只铺这种石板。左右两缘是一湾静水，水色是墨蓝，边上有一圈更浅的蓝。石岸上：红包那种橙的小圆纸灯、几片扁的白花瓣、深色小圆石。正面厚度带和第一章一样高，颜色是深石板。
