# 道具图标 v4：去掉白边，蓝品质三件换色，回旋镖回到发光

画风延续 v3 的扁平正面手绘贴纸：深可可棕圆润墨线是物体最外一圈，直接落在纯白底上。颜色用柔和的马克笔过渡。

## 闹钟（蓝卡，改暖黄）
正面双铃闹钟。钟身是向日葵那种暖黄，从上到下过渡到琥珀色。表盘是暖米色。顶上两只同色暖黄铃，中间一颗小珊瑚红按钮，底下两只小脚。指针是深棕。最外圈是深可可棕墨线。

## 冰块（蓝卡，改霜白）
正面一块圆角冰块。主体是结霜的奶白色，只在底部带一点很淡的薄荷绿。正面一朵白色六角雪花。最外圈是深可可棕墨线。

## 能量饮料（蓝卡，改柑橘橙）
正面直立易拉罐。罐身是熟柑橘那种橙，过渡到柿子红橙。顶盖是浅银灰，带一个小拉环。正面一枚金币黄闪电。最外圈是深可可棕墨线。

## 回旋镖（稀有，回到发光）
正面三片弧形飞刃绕着发光核心。刃身从牡丹粉过渡到紫罗兰，刃缘是泳池青的光边，圆心一颗发白蓝光的五角星，周围有柔和光晕。最外圈是深可可棕墨线。颜色和光效对齐上一版发光回旋镖。
