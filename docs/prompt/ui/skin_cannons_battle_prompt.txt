六门塔防手游里的迫击炮台贴纸，排成 3 列 × 2 行，均匀散放在一整片纯品红 #FF00FF 背景上，每门炮之间隔着大片品红空地。画法和参考图里的怪物完全一致：休闲卡通、深酱油色粗描边、外圈一道细细的奶油色纸边、两层硬边明暗、几处小白高光、圆滚滚的胖比例、玩具感。

每门都是矮胖的迫击炮造型：粗短的炮管几乎竖直立着，炮口朝向画面正上方，看得见炮口圆圆的黑色炮膛；炮座在下方正面朝着观众，左右基本对称；整体比宽度略高一点。六门大小一致、底边对齐。

上排左：铸铁锅那种黑铁炮管，炮口一圈黄铜箍，炮座是暖橡木色木板箱，两侧各一个木轮子，箱子钉着圆头铁钉，绕一圈麻绳。
上排中：红包那种红的亮漆炮管，三道新金币那种黄的金箍，炮口镶金边，炮座是朱红漆盒，盒面刻金色祥云纹。
上排右：宋代青瓷花瓶那种淡青绿炮管，表面有白色细开片纹，炮口一圈深青釉边，炮座是浅色雕花木托，垫着靛蓝布。
下排左：新金币那种明黄金炮管，炮身嵌一颗石榴籽那种红的宝石，炮座是一圈金币叠成的矮塔，金币边缘带齿纹。
下排中：一颗中国龙头仰着头朝天，龙嘴大张朝上就是炮口，嘴里冒出一小团篝火那种橙黄火焰，龙鳞是红辣椒那种红，龙角和龙须是新金币那种黄，下面是黑铁底座，铸着火焰纹。
下排右：一只白色招财猫正面坐着，双爪抱住胸前一门竖直朝上的新铜币那种橙铜色短炮，炮身挂一枚方孔铜钱徽章，猫戴红包那种红的项圈和金铃铛，坐在一只红包那种红的鼓鼓福袋上，袋口系金绳。

画面里只有这六门炮和品红背景。
