# 炮台词条图标 v1（平面手绘，无白边，颜色拉开）

九张都是正面扁平手绘图标。深可可棕圆润墨线是最外一圈，直接落在纯白底上。色块用柔和马克笔过渡，图形撑满画面大约 85%。黄底上要能分开，所以每张用自己的主色。

1. 伤害 damage：正中一颗炭黑圆炮弹，身后一大团扁平的朱红色、柑橘橙、金币黄放射芒。
2. 射速 rate：钴蓝秒表，米白表盘，珊瑚红按钮，左侧三道橙色速度线。
3. 炮台数 guns：并排两根胖炮管，一根柑橘橙，一根天空青，炮口是深灰。
4. 开局金币 gold：三枚叠起的古铜金币，正面一颗珊瑚红星，最上面嵌一颗翠绿宝石。
5. 基地生命 hp：天空蓝盾牌，正中一颗樱桃红心。
6. 暴击 crit：扁平的尖角爆炸星，牡丹粉到紫罗兰，中心一颗金币黄小星，旁边两粒橙色火星。
7. 金币收益 goldgain：皇家紫钱袋，袋口涌出古铜金币，旁边一支翠绿向上的箭头。
8. 改装折扣 draftcut：青绿色价签，金线挂环，签面一支翠绿向下的箭头。
9. 道具冷却 itemcd：胖沙漏，玻璃是泳池青，上下沙子是牡丹粉，顶上一点橙色火星。
