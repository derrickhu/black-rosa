一张塔防手游的炮台朝向样张，横版 16:9。整张背景是一块均匀的纯品红 #FF00FF。

七门炮分成两排。上排四门，从左到右均匀排开。下排三门，放在画面下半部的正中。七门大小接近，底边对齐自己那一排，彼此隔着宽宽的品红空地。

画法和游戏炮台图标一致：玩具卡通，圆滚滚，平涂色块，每块颜色带一块更深的暗面，再加几颗小白高光。所有外轮廓和内部结构线都是同一支细钢笔，墨汁那种黑，线宽均匀，线很细。细黑线的外侧直接接到品红背景。

每一门都是正视图。炮管是一根笔直的圆柱，轴线和画面的竖边平行。炮口是一个正圆，圆心在这门炮的水平正中、这门炮的最上方，圆洞里是黑膛。底座在最下方，左右对称。

上排左，木炮：暖橡木色木板箱当炮座，四只小木轮，箱面钉着圆头铁钉，绕一圈麻绳。炮管是铸铁锅那种黑铁，竖直立在箱子上，炮口一圈黄铜箍，黑色圆膛在最上方。木板缝、轮子、麻绳都用那条细黑线勾出来。

上排左二，糖果炮：粉色礼物盒当炮座，盒子正面系一只薄荷绿大蝴蝶结，两侧轮子是彩虹棒棒糖。炮管是圣诞拐杖糖那种红白螺旋，竖直立在盒子上，炮口是草莓奶油那种粉色甜甜圈，上面撒彩色糖针，黑色圆膛在最上方，管身侧面贴一颗红白薄荷糖。

上排右二，机甲炮：下方是一台短胖的深灰履带小车，履带是深灰橡胶，车身一道柠檬那种黄的警示斜纹，一盏小黄灯。炮管是游泳池那种天蓝色的玩具装甲，白色护板一节一节，竖直朝上，炮口一圈荧光棒那种青色光环，黑色圆膛在最上方。

上排右，黄金炮：下方是一只打开的暖橡木色海盗宝箱，铁皮包角，箱里堆满新金币那种黄的金币。炮管是新金币那种明黄金，竖直朝上，侧面嵌一颗石榴籽那种红的大宝石，黑色圆膛在最上方，管身几颗小白星光。

下排左，龙炮：下方是一块左右对称的黑铁底座，铆钉清楚。一条红辣椒那种红的中国龙正面对着观众，龙头在底座正上方。龙嘴是一个朝天的黑色圆膛，圆膛上方紧接着就是品红背景。龙角和龙须是新金币那种黄，眼睛在圆膛两侧，鳞片用细黑线勾出。

下排中，福袋炮：下方是一只红包那种红的鼓鼓福袋，袋口系金绳。一只白色招财猫坐在袋子旁边，脑袋是完整的白毛，两只尖耳朵，两耳之间是白毛，闭眼笑，戴红项圈和一颗金铃铛，一只爪子举起。一门短炮竖在猫的身前，炮管是新铜币那种橙铜色圆柱，黑色圆膛是这根铜管自己的上口，停在胸口的高度，低于耳朵。炮身挂一枚方孔铜钱。

下排右，冰炮：最下方是一朵左右对称的胖白云。炮管是冰川那种淡蓝白色的竖直圆柱，插在云的正中，黑色圆膛在云的正上方，管身一颗五角金星，管口一圈往下垂的小冰晶围着圆膛。
