六门手游炮台贴纸，排成 3 列 × 2 行，均匀散放在一整片纯品红 #FF00FF 背景上，每门炮之间隔着大片品红空地。画法和参考图里的怪物完全一致：休闲卡通、深酱油色粗描边、外圈一道细细的奶油色纸边、两层硬边明暗、几处小白高光、圆滚滚的胖比例、玩具感。每门炮都是四分之三侧视，炮管斜着翘向右上方约 35 度，稳稳坐在自己的炮座上，六门炮大小一致、底边对齐。

上排左：炮管是擦亮的铸铁锅那种黑铁色，炮口一圈黄铜箍，炮座是暖橡木色的木板车架，两个木轮子，木板钉着圆头铁钉，车架上绕一圈麻绳。
上排中：炮管刷着红包那种红的亮漆，三道新金币那种黄的金箍，炮口镶金边，炮座是一只朱红漆盒，盒面刻金色祥云纹。
上排右：炮管是宋代青瓷花瓶那种淡青绿，表面有白色细开片纹，炮口一圈深青釉边，炮座是浅色雕花木托，托上垫一块靛蓝布。
下排左：炮管是新金币那种明黄金，身上嵌一颗石榴籽那种红的宝石，炮座是一摞摞金币叠成的小塔，金币边缘带齿纹。
下排中：炮管做成一颗中国龙头，张大的龙嘴就是炮口，龙嘴里含着一团篝火那种橙黄火焰，龙鳞是红辣椒那种红，龙角和龙须是新金币那种黄，炮座是黑铁底座，四角铸火焰纹。
下排右：一只白色招财猫抱着一门短胖的炮，猫戴红包那种红的项圈和一颗金铃铛；炮管是新铜币那种橙铜色，炮身挂一枚方孔铜钱徽章，炮座是一只红包那种红的鼓鼓福袋，袋口系金绳。
