> ### 生这批图标踩过的四个坑（再生时照着避）
>
> 1. **提示词里不能出现 `glossy`、`sheen`、`cel shading`、`plump`**。第一版写了这些，
>    出来一批糖果消除那种 3D 塑料质感，和平面卡片风完全不是一路。要反向写死：
>    `flat solid colour only`、`hard crisp edge between tones`、`no bevel / no gloss /
>    no 3D / no drop shadow`。
> 2. **内置生图搞不定平面**，很容易往立体写实跑；这批最终是用 **Gemini NB2**
>    （`gemini-3.1-flash-image-preview`，`--image-size 2K`）出的。

>    而这四样都在清单里，模型直接把参考当成「扩充这套图标」，原样抄了一行，
>    剩下 12 格自由发挥成了通用奇幻 RPG 图标（城堡、宝箱、剑）。
>    参考板必须是**抽象几何色板**，只传递「怎么上色」。
> 4. **渐变靠提示词压不住，靠后处理压**。模型对球体、圆柱这类有体积感的形状
>    始终偷偷加径向明暗（试了三版都在）。`process_ui_icons.py` 里用**无抖动的
>    12 色调色板量化**直接压平，在 512px/格 上做、再缩到 128px，抗锯齿自然回来。

## 0. 支配性约束

**未改装的世界必须能用黑白看完。** 宣纸底 + 石墨人/炮/墨点弹。饱和色只出现在：

- 格子里的汉字牌，以及牌点亮的那一列光
- 穿过改装后的子弹和拖尾
- 灼烧 / 冰 / 爆炸 / 命中
- 二阶段精英和关底的衣服点色
- 同列三章「显形」

封面和中局图必须是「宣纸黑白 + 至少一列已被你染了」。纸是战场，也是牌。

竖屏 720×1280。正视弹幕塔防。从上到下：刷怪 → 6 列格（最多 3 层，三层位置预留下方）→ 漏怪线 → 炮串 → 底栏。上面战斗区要大，格子不要居中。

真机大约：敌人 50–90px，牌标 88px，底栏炮 70px。放大才好看的细节等于没有。

## 1. 判定三条

| 原则 | 判定 |
|---|---|
| 剪影先于细节 | 细节要缩小主体就砍细节 |
| 明度先于色相 | 先和宣纸拉开明度，再上色 |
| 一个记忆点 | 每种敌、每张牌只放大一个形 |

彩色弹必须从宣纸上跳出来。火不要土黄，冰不要灰蓝，追踪不要脏紫。透明色图叠在浅底上，不要黑底加色，不要碎渣雪花点。火 / 冰是实心元素形，不要空心套黑核。叠字分层：速是绿色拖尾，晕是淡金光晕。

## 3. 形状语言

体积 = **2～3 档平涂色阶**（亮面 / 本体 / 暗面）+ 近黑厚描边。不要纸片，不要软阴影 3D。

人、炮仍是**同一套线**：圆角墨玩具。格子上的改装改走平面卡牌，不跟它们抢体积和颜色。

- 炮：略俯视短圆柱管，管顶亮、侧面暗、圆黑座。2～4 门固定相邻。
- 敌人：能读出头身手脚的墨线人。初期石墨；后期只在衣服上点色。不是三角/环/墨点。
- 改装在格子上是**汉字牌**，不是立体玩具、也不是墨滴。
  - 选牌 / 入格：同一张宣纸方卡 + **一个一看就懂的字**
  - 字边缘完整（赵云与阿斗那种），不要泼墨飞白
  - 字要有笔势，不要端正电脑字
  - **字效融进笔画（v13 起）**：字身保持手写墨笔，只把**一个指定的小笔画**（点、短撇、末笔）换成该字的元素意象并上色，骨架一笔不动。只改小笔画是为了不写错字，也让 25 个字能共用一条规则。
    - 常驻字：墨黑 `#1A1410` 字身 + 元素主色意象（火＝橙火舌、冰＝蓝冰碴、雷＝紫电花……）
    - 词组字：金 `#E8B43A` 字身 + 墨黑意象。和常驻字正好反过来，单放在格子上一眼看出「这张要凑齐才醒」
    - 道族三字（分 / 穿 / 重）没有专属色，意象用石墨 `#6A6A6A`，靠形状区分
    - 意象**不得放大、不得飘离字身**，否则读起来像字旁边摆了个图标
  - 字图不带卡框；宣纸方卡由游戏统一套。字按墨迹包围盒缩到卡芯 64%，新字走 `docs/prompt/runtime/heaps_v13_glyphfx.md`
  - 不要动画。鲜艳动态留在炮弹上
  - 后续：同列多字可组合；本版先锁单字
- 禁止喷灯、钳子、钻头、天线、节拍器。
- 2 / 3 星只在格角小菱，不改堆的基本形。
- 禁止给战场加山门风景框。

## 4. 页面（对 A3 原型）

流程：`Home → Battle → Draft → Place → Confirm → Result`。允许**三段**底栏，不要五 tab、不要城市、不要抽卡机。

**首页**（`01_home`）

- 整屏纸白墨黑
- 顶栏常驻：体力 / 墨 / 星 三个实心剪影，不用 emoji。体力下面挂一行恢复倒计时小字
- 底栏三段：`炮台 | 出征 | 技能`。选中态实心墨底白字，未选描边墨字
- 切页只切子容器，顶栏和底栏不重建
- **出征**：墨线横匾标题 + 2×4 关卡章。已通 1～3 小菱；未解锁灰锁；已通过的章挂「体力 2」角标，没通过的挂「免费」
- **炮台**：上是炮台预览 + 4 个皮肤格；下是 5 张升级卡（2 列），每张左名右价，底下一排等级小菱
- **技能**：上是两个装备槽；下是 6 张技能卡（2 列）

**战斗**（`02_battle`）

- 顶：左墨钱、中波次、右能量。左右对称，别把读数都堆在一侧
- 其下 toast
- 场是宣纸黑白；只有牌、列光和穿过后的弹上色
- 底：浅「撤退」+ 实心黑「改装」+ 红心。不要再挂一排选牌
- 右下角竖排两个技能键，92×92，键内一圈径向充能。不要压到炮串拖动区

**三选一**（`03_draft`）

- 战场压暗，相机不关
- 白纸描边大板，三张竖卡
- 上墨堆、中名、下短描述
- 永远 1 星
- 底浅「看广告重刷」

**放置 / 覆盖**

- 空格绿罩、同牌金罩、异牌红罩、满星压暗
- 覆盖：一句 + 黑「覆盖」+ 浅「取消」

**结算**

- 通关：大菱星、「墨 +N」、「看广告 墨翻倍」、「下一关」主按钮、「首页」次按钮
- 失败：「续命」+「首页」，并写明体力不扣

## 5. 实体

| 敌 | 记忆点 |
|---|---|
| Walker | 蹒跚墨线人，圆头垂臂 |
| Runner | 更瘦、前倾 |
| Shield | 端圆盖 |
| Swarm | 三只更小的挤一簇 |
| Strafer | 横步、身更宽 |
| Elite | 帽或围巾点色 |
| Boss | 巨汉 + 大盖 |

| 牌 | 格子上（汉字） |
|---|---|
| 火 / 冰 / 分 / 瞄 / 速 + 金 / 木 / 水 / 土 / 风 / 雷 / 毒 / 惑 | 常驻，过格就改弹 |
| 穿 / 炸 / 重 / 晕 | 常驻但要蓄，触发发才改弹 |
| 秒杀 / 万箭 / 击退 / 连斩 | 黄字，单放淡墨沉睡，同列凑齐才醒 |

沉睡字淡墨。成词后两字恢复实墨。充能用格角墨点。触发弹在现有主体上盖印（杀印 / 晕圈），不另做整弹皮。

### 炮弹：五个槽，不是一串 if

炮弹是「小墨点 + 透明色形 + 色带」。未改装是石墨点。一发最多同时亮五层，**同槽只亮一个形，异槽全亮**：

| 槽 | 谁占 | 长什么样 |
|---|---|---|
| 体 Form | 元素主形，一发只一张 | 火舌 / 霜滴 / 毒滴 / 水花 / 土块 / 爆核 / 红斩 / 针 |
| 尾 Trail | 速、瞄、风 | 色带，最多 2 条并行 |
| 环 Halo | 晕、雷、金 | 半透明圈 |
| 绕 Orbit | 风、木 | 两颗绕核转的小点。分不占槽，只裂成多发 |
| 晕光 Bloom | 重、金 | 软光盘，颜色永远混合 |

**体槽有图时要藏掉底下的黑弹丸**，否则就是被明令禁止的「空心包黑」。
赢下体槽的那个字，颜色不是纯色，而是往「全部元素的混色」拉 35% —— 被压掉的元素在弹身上仍看得出来。
重只略放大（最多 1.6 倍），不撑满格，且**只放大视觉不放大碰撞**。

### 命中：三层，不是三套爆炸

1. **墨溅底**：始终有，白墨四帧，按混色染。
2. **元素层**：只播一个元素的四帧，被压掉的元素退化成边上最多 2 颗色点。
3. **事件层**：杀印 / 晕圈 / 推折 / 针尖，单帧盖印，没有事件就不出。

命中停顿只由事件层和重决定，元素层不产生停顿。

### 敌人身上：六颗标记

灼烧头顶火苗、毒气泡按层数出 1～4 颗、缓脚下水纹、冻全身冰壳、晕头顶金环转圈、惑紫漩涡反向慢转。
标记要**反向抵消敌人的呼吸缩放**，否则会跟着一起胀缩。当前是运行时烘的 64² 三张基图靠 tint 派生，换真图集时只改 `DotMarks`。

格子上的火 / 冰叠光晕，有色牌会淡染那一列。

## 6. 工程口径

- 可拉伸壳用代码画：[`UiKit.cs`](../Assets/Scripts/UI/UiKit.cs) 的描边框、按钮、面板。不出九宫格贴图。
- 生图只做固定件：炮、敌、堆、弹、图标。未确认前原图留在 `game_assets`。
- 运行时堆 / 人 / 炮的程序形走 [`InkArt.cs`](../Assets/Scripts/View/InkArt.cs)，必须是色阶+描边，不要单色剪影。
- 图标实心剪影 + 同一套墨描边。不用 emoji，不用线性图标。
- 页面组件：`LobbyScreen` `BattleHud` `DraftPanel` `ConfirmPanel` `ResultPanel`。`GameFlow` 只编排。
- 表现层只读槽位，不读 `CardId`：`ShotLook.cs` 解出五槽，`InkShot` / `InkFx` / `InkDot` 照着画。加字是往优先级数组里插一个 id，不是加一条 `else if`。
- **贴图预算**：磁盘 6.0 MB、运行时 35.6 MB。全部贴图限 256²。`Assets/Resources/Art/` 下的字图要在 CPU 上套卡框，必须可读且不压缩；`Resources/Art/Vfx/` 下只当贴图用，可读关掉、压缩打开。分流在 `InkArtImporter.cs`，不要绕过它手改导入设置。
- 黑底特效的压黑走离线 `docs/prompt/runtime/vfx_crush.py`，不在运行时逐像素处理。母版存仓库内 `art_src/`（在 `Assets/` 外，不会被打包）。
- `Resources/` 是整包打进去的，不要往里丢没有代码引用的实验素材。

## 7. 真机适配（微信小游戏）

编辑器里好看不代表真机上好看。这一节每条都是真机上踩出来的，不是预防性规范。

### 字体：子集化 + 两个字重，加中文必须重建

`Assets/Resources/Fonts/Ink.ttf`（正文 400）和 `InkBold.ttf`（标题/数值 700）是
**Noto Sans SC 按工程字表切出来的子集**，各约 99 KB。原字体 OFL 1.1，免费商用，
许可证全文在仓库根 `LICENSES/`，母版在仓库外 `game_assets/black-rosa/字体/`。
子集改名成 `Ink Sans SC` 是必须的 —— Noto Sans SC 源自思源黑体，原声明里
`Source` 是保留字体名，改造版不能沿用。

- **加了新中文，必须重建字体**：`python3 docs/prompt/runtime/build_font.py --build`。
  忘了重建的后果是缺的字在真机上渲染成**空白**——编辑器里 macOS 会回落到系统字体，
  本地永远看不出来。这条已经出过一次事故：真机上「炮弹伤害 +8%」显示成「炮弹 +8%」、
  「出征」整个消失，读起来完全通顺，比报错难查得多。
  `csharp_check.sh` 里挂了 `--check` 来拦这件事。
- 子集里 `.notdef` 保留轮廓，缺字会渲成豆腐块而不是空白 —— 就是为了让下次一眼看见。
- **不要写 `fontStyle = FontStyle.Bold`**，用 `UiKit.Bold(text)` 换真粗体字重。
  Unity 的合成粗体是把字形往四周抹一圈，汉字笔画密，20px 上会糊成一团。
- 不要用系统字体名兜底（`Heiti`/`PingFang` 都是苹果系统字体，商用有授权风险，
  而且小游戏运行时根本没有这些字体）。

### 顶栏：让到微信胶囊按钮下沿

右上角那个「···  ⊙」胶囊是微信画在游戏画布**之上**的，既不在 `Screen.safeArea` 里，
Unity 也看不见它。`ScreenFit` 通过 `WxBridge.CapsuleBottomFrac()` 读
`WX.GetMenuButtonBoundingClientRect()`，把 `TopPad` 压到胶囊下沿之下再留 12。

- 顶栏三个数值药丸横着要 570，720 宽里腾不出胶囊那 200 来个单位，所以只能让高度。
  这是小游戏的通行做法，让出来的是高度不是功能。
- 团结导出的包里 `Screen.safeArea` 在刘海机上会退化成整屏，所以安全区也同时读
  微信自己报的那份（`WxBridge.SafeInsetFrac()`），两边取大的。
- 顶栏往下让之后，战斗顶栏那排药丸会多压住一点走怪区。`BattleHud` 的额外偏移
  因此只加 8 而不是 30 —— 顶栏每往下一格，玩家能提前看见敌人的时间就少一点。

### 布局不能按 720x1280 写死

`CanvasScaler` 是按宽匹配的，长条屏上画布有 **1558** 个单位高，不是 1280。
算「排完还剩多少」要用 `ScreenFit.CanvasH`，用 `DesignH` 会在真机上白留近 280。
反过来，16:9 和平板上内容区只有 930 出头，按长条屏调好的间距会顶到底栏下面。

所以卡片行距（`HomeScreen.Slot`）和印章尺寸（`BuildSortie`）都按内容区实际高度收缩，
不写死。卡片本身不缩 —— 卡里的图标、两行字、等级点、价格药丸全是按 `CardH = 204`
定的偏移，缩卡等于把里面全挤乱。

### 底栏是底栏，不是三个按钮

`UiKit.TabBar` 是整条悬浮药丸：淡底 + 图标不透明放大 + 标签换粗体主色，三件事一起说选中态。
按钮的意思是「按一下发生一件事」，底栏的意思是「我现在在哪一页」；长得一样时玩家
分不清哪些能按出结果、哪些只是换个地方看，而且三个立体按钮并排在底部会把视线从内容上抢走。

选中格**不要**在图标底下垫饱和色块 —— 这批手绘图标自己带颜色和描边，垫一层就是撞色。

### 核对手段（没法跑 Play 模式时）

- `docs/prompt/ui/render_home_final.py`：按源码坐标预渲染三页，**按两种机型各渲一套**
  （长条手机 / 16:9）。只按一种比例渲等于没渲 —— 今天两处顶穿底栏的排版就只在 16:9 上出现。
  脚手架里的文案必须和 catalog 一字不差，抄错了渲出来的豆腐块全是脚手架自己的字，
  反而掩盖真问题。
- `docs/prompt/runtime/check_text_fit.py`：按真字体量每个 `UiKit.Label` 的字宽。
  预渲染看不出折行 —— PIL 一行画到底，而 `Text` 是 Wrap + Overflow，超宽会折行再顶出框，
  压到上下相邻的元素上。这也算「字显示不全」。
