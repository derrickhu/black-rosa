## 0. 支配性约束

**未改装的世界必须能用黑白看完。** 饱和色只出现在：

- 格子里的改装墨堆
- 穿过墨堆后的子弹
- 灼烧 / 冰 / 爆炸
- 二阶段精英和关底的衣服点色
- 同列三章「显形」

封面和中局图必须是「纸世界 + 至少一列已被你染了」。

竖屏 720×1280。正视弹幕塔防。从上到下：刷怪 → 6 列格（最多 3 层，三层位置预留下方）→ 漏怪线 → 炮串 → 底栏。上面战斗区要大，格子不要居中。

真机大约：敌人 50–90px，牌标 88px，底栏炮 70px。放大才好看的细节等于没有。

## 1. 判定三条

| 原则 | 判定 |
|---|---|
| 剪影先于细节 | 细节要缩小主体就砍细节 |
| 明度先于色相 | 先和纸面拉开明度，再上色 |
| 一个记忆点 | 每种敌、每张牌只放大一个形 |

彩色弹必须从纸白和墨黑里跳出来。火不要土黄，冰不要灰蓝，追踪不要脏紫。

## 3. 形状语言

体积 = **2～3 档平涂色阶**（亮面 / 本体 / 暗面）+ 近黑厚描边。不要纸片，不要软阴影 3D。

人、炮仍是**同一套线**：圆角墨玩具。格子上的改装改走平面卡牌，不跟它们抢体积和颜色。

- 炮：略俯视短圆柱管，管顶亮、侧面暗、圆黑座。2～4 门固定相邻。
- 敌人：能读出头身手脚的墨线人。初期石墨；后期只在衣服上点色。不是三角/环/墨点。
- 改装在格子上是**汉字牌**，不是立体玩具、也不是墨滴。
  - 选牌 / 入格：同一张宣纸方卡 + **一个一看就懂的黑字**
  - 字是实心黑字，边缘完整（赵云与阿斗那种），不要泼墨飞白
  - 字要有笔势，不要端正电脑字；效果必须长进某一笔里，不要旁边贴图标
  - 零件分开画（完整黑字 + 饰图），合成/拆笔/叠加走编辑器「墨弹防线 / 汉字牌合成」
  - 字图不带卡框；宣纸方卡由游戏统一套，避免每张生成图框线不一致
  - 不要动画。鲜艳动态留在炮弹上
  - 后续：同列多字可组合；本版先锁单字
- 禁止喷灯、钳子、钻头、天线、节拍器。
- 2 / 3 星只在格角小菱，不改堆的基本形。
- 禁止给纸战场加山门风景框。

## 4. 页面（对 A3 原型）

流程：`Lobby → Battle → Draft → Place → Confirm → Result`。不要底栏五 tab、城市、抽卡机。

**大厅**（`01_lobby`）

- 整屏纸白墨黑
- 上：墨线横匾，标题运行时叠
- 中上：星 / 炮 / 钱 三个实心剪影，不用 emoji
- 中：2×4 关卡章。已通 1～3 小菱；未解锁灰锁
- 下：两行说明

**战斗**（`02_battle`）

- 顶：墨钱、3 颗红心、波次
- 其下 toast
- 场黑白；只有墨堆和穿过后的弹上色
- 底：浅「撤退」+ 实心黑「改装」。不要再挂一排选牌

**三选一**（`03_draft`）

- 战场压暗，相机不关
- 白纸描边大板，三张竖卡
- 上墨堆、中名、下短描述
- 永远 1 星
- 底浅「看广告重刷」

**放置 / 覆盖**

- 空格绿罩、同牌金罩、异牌红罩、满星压暗
- 覆盖：一句 + 黑「覆盖」+ 浅「取消」

**结算**

- 通关：大菱星、「下一关」主按钮、「大厅」次按钮
- 失败：「续命」+「大厅」

## 5. 实体

| 敌 | 记忆点 |
|---|---|
| Walker | 蹒跚墨线人，圆头垂臂 |
| Runner | 更瘦、前倾 |
| Shield | 端圆盖 |
| Swarm | 三只更小的挤一簇 |
| Strafer | 横步、身更宽 |
| Elite | 帽或围巾点色 |
| Boss | 巨汉 + 大盖 |

| 牌 | 格子上（汉字） | 穿过后 |
|---|---|---|
| 分化 | **分** + 分叉箭头图 | 裂成多发 |
| 加火 | **火**，两点换成两团火 | 燃烧弹 |
| 加冰 | **冰**，水旁换成冰晶图 | 冰弹 |
| 追踪 | **瞄** + 准星图 | 拐弯弹 |
| 穿透 | **穿**，中竖换成矛图 | 尖弹 |
| 爆炸 | **炸**，字下爆炸图 | 爆弹 |
| 加速 | **速**，辶末梢人字标 | 更快 |
| 重击 | **重**，田里压沉 | 更粗 |

默认弹先用重击那套黑白弹（`heavy_shot`）。只有火 / 只有冰换主体；火+冰用融合弹 `fireice_shot`。追踪用紫尾叠在任意主体上，不换整弹。命中闪光：白核 → 饱和中层 → 深外沿，硬边，黑底，可按火/冰/炸染色。

## 6. 工程口径

- 可拉伸壳用代码画：[`UiKit.cs`](../Assets/Scripts/UI/UiKit.cs) 的描边框、按钮、面板。不出九宫格贴图。
- 生图只做固定件：炮、敌、堆、弹、图标。未确认前原图留在 `game_assets`。
- 运行时堆 / 人 / 炮的程序形走 [`InkArt.cs`](../Assets/Scripts/View/InkArt.cs)，必须是色阶+描边，不要单色剪影。
- 图标实心剪影 + 同一套墨描边。不用 emoji，不用线性图标。
- 页面组件：`LobbyScreen` `BattleHud` `DraftPanel` `ConfirmPanel` `ResultPanel`。`GameFlow` 只编排。
