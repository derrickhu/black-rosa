# D · 技能页

和炮台页同一套纸面、描边、黄钮，上面那块装备区换形制，不再套砚台展板。

## 和炮台页哪里要分开

炮台是「收藏柜」：深核桃木砚台、左上朱红纸签、格子里摆皮肤。

技能是「两个键」：局内右下角两张符，共用一条墨。上面就要长成符，不要再做一个矮一截的砚台。

## 技能页从上到下

1. **货币**贴顶：体力 / 墨，三页同一套药丸。
2. **符纸夹**（装备区，两张美术资源）：
   - `panel_spell_rod`：整根竹竿和左端朱红印「技」画在一张图里，不要九宫格
   - `panel_spell_tag` / `panel_spell_tag_on`：带红绳的空牌子，字和图标运行时叠上去
   - 已装用红框那张；空槽用素面，居中写「空槽」
3. **技能目录**（2×3 带厚度的贴纸卡，一张一个技能）：
   - 左：圆形色标图标
   - 中：名字 + 一句效果
   - 底左：耗 xx 墨
   - 底右：已装备 / 新铜币黄钮 / 差墨灰字 / 星门槛 / 通关锁
   - 差墨仍是白卡；星/通关锁才换灰卡 + 右上锁
   - 卡壳用宽扁的 `panel_card` / `_on` / `_dim`，和原型同一套票形，不要方块立体壳
4. **底栏**贴死屏幕下沿。这一页选中「技能」：瓷牌垫高，字用红包朱红。

## 和现规则对齐

- 六个技能仍是 墨爆 / 定身 / 强攻 / 横扫 / 泼墨 / 回血
- 两个装备槽共用一条局内墨
- 解锁走买墨、攒星、通关，不进牌池、不吃星升级
