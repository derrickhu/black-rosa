# D · 炮台列表 + 插画底栏

参考外卖那页的骨架，换成墨字防线的纸面卡片风。只改结构，不改数值。

## 从参考图借什么

| 参考 | 落到我们 |
|---|---|
| 上半块「主角」黑板 + 角色格 | 上半块「炮台」砚台展板 + 2×2 皮肤卡 |
| 每格一张人，选中描边 | 每格一门炮，只换皮肤色，选中用红包那种朱红描边 |
| 黑板下一条收益摘要 | 展板下一条「当前 2 门炮」——炮数只认加成 |
| 下半全宽升级行，右侧按钮 | 5 条加成改成全宽行：左图标、中名字+等级+一句效果、右价格钮 |
| 底栏（参考里没有，我们自己的痛点） | 铺满屏宽的插画纸卷托盘，三枚大图标站上去 |

不借绿黑板、不借剪影小人、不把皮肤和加成再揉成两列方卡。

## 炮台页从上到下

1. **货币**贴顶：体力 / 墨，和出征页同一套药丸。
2. **砚台展板**（深核桃木那种褐，不是绿）：
   - 左上一条朱红纸签写「炮台」
   - 2×2 白瓷卡片，每张只画一门炮 + 皮肤名
   - 素笔使用中：红包朱红描边
   - 未解锁：灰炮 + 门槛小字（需 6 星 / 通关）
3. **摘要条**：当前 2 门炮。让玩家看见「炮数在加成里，不在皮肤里」。
4. **加成列表**（白瓷行，一行一条）：
   - 左：现成手绘图标（伤害爆炸、秒表、金币、盾心、锁）
   - 中：名字 + `Lv.x`，下一行效果
   - 右：买得起是新铜币那种黄钮；买不起/锁定是灰字
5. **底栏**贴死屏幕下沿，吃满宽。

皮肤点格子就换，不再单独弹一层。能力只出现在下面的列表里。

## 底栏为什么要出图

现在的底栏是程序九宫格画出来的白胶囊，三个 48px 小图标浮在一大块空白里，所以空、薄、像没做完。

改成一张铺满宽的**插画托盘**（宣纸卷轴摊开，两端是深木轴），三枚印刷贴纸级图标站在托盘上。选中那枚垫一块宣纸圆角牌，字用红包朱红。未选中只留图标和浅字。这张托盘是美术资源，运行时拉伸，不再用 `Stroke` 画壳。

## 和现规则对齐

- 皮肤零数值，预览只画一门炮
- 几门炮只走「炮台数」加成
- 加成仍按累计星露面；列表不够五条时，只画已露面的 + 下一张锁定预告
