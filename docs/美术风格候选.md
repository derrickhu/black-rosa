# 墨弹防线 · 三套风格候选

**已锁定 A3 宣纸 / 墨堆。** 正式约束见 [美术风格圣经.md](./美术风格圣经.md)，色值见 `InkTheme`。B / C 仅作对照归档，不再跟进实现。

---

## A · 宣纸 / 墨堆（A3，已锁）

敌人、炮锁 A2 单位表。改装回到**火堆式实体**，和人、炮同一套描边与色阶，不是修理工具。

- 页面主色必须是纸白 + 墨黑。颜色只出现在格子里的堆、以及穿过后的弹。
- 选牌：白卡上画一堆火。入格：略立体的火堆。穿过：燃烧弹。冰/分化同构。
- 禁止喷灯、钳子、钻头等第二套画风。
- 风格块：[`docs/prompt/style_a/_style_block.txt`](./prompt/style_a/_style_block.txt)
- A3 原图：`game_assets/black-rosa/美术/风格原型/A3/cursor/`

## B · 木刻街机（Woodcut Arcade）

海报木刻，黑多、块大，颜色像套色油墨。

- 参考：Hades 粗框、Cult of the Lamb 图章、Dead Cells 高对比、Brotato 商店卡。
- 底：`#E8E4DC`。描边占比接近 28–33%。炮：连体木刻炮车。敌：更凶的块。
- 冲击：彩色弹是第二块版，命中是色块不是光斑。
- 风险：UI 全黑会压战场，面板必须大留白。
- 风格块：[`docs/prompt/style_b/_style_block.txt`](./prompt/style_b/_style_block.txt)

## C · 萝卜剪影（Casual Silhouette）

保卫萝卜式可读圆形，世界仍是纸，颜色仍是改装才给。

- 参考：保卫萝卜、Archero、弹壳特攻队、PVZ2 简化。
- 底：暖纸，圆角胶囊。炮：圆墩墨炮。敌：可认物种的单色剪影。
- 冲击：圆、亲、好变现。
- 风险：滑向通用超休闲。禁止粉彩全身涂满。
- 风格块：[`docs/prompt/style_c/_style_block.txt`](./prompt/style_c/_style_block.txt)
