# 墨弹防线（black-rosa）

竖屏塔防射击 + 列式子弹改装。策划见 [docs/墨弹防线-策划案.md](docs/墨弹防线-策划案.md)。

## 打开工程

1. 用团结引擎 Hub 打开本仓库根目录（编辑器 `2022.3.62t8` / Tuanjie 1.9.0）。
2. 打开 `Assets/Scenes/Main.scene`，点 Play。
3. 大厅选第 1 关。左右拖底部炮串；金币够了点「改装」。

不需要在编辑器里摆物体。战场和 UI 都是运行时创建。

## 微信开发者工具

团结规定：微信子平台没 Active 时，转换 SDK 不编译，顶栏也就没有「微信小游戏」。

1. **File → Build Settings**
2. 左边选 **MiniGame**（标题栏已是 MiniGame 就对了）
3. 右边 **Sub Platforms** 把「微信小游戏」点成 **Active**，等脚本编译完
4. 这时顶栏才会出现 **微信小游戏 → 转换小游戏 → 生成并转换**
5. 或在同一窗口勾选 `WeChat_Debug`，点右下角 **Build**

导出路径用仓库里的 `wechat-minigame`，首包选「小游戏包内」。然后用微信开发者工具打开 **`wechat-minigame/minigame/`**，不要打开仓库根目录。AppID 默认 `wxad27f529c95e582c`。

第一次编译 WASM 可能要十几分钟。产物在 `wechat-minigame/`，不入库。

开发者工具里若提示 `UnityPlugin` / 快适配未开通：用正式 AppID 登录 [微信公众平台](https://mp.weixin.qq.com/)，在「能力地图 → 开发提效包 → 快适配」开通。测试号不能用。模拟器可能和真机不一致，以真机预览为准。

## 操作

- 战斗中左右拖：移动整串发射器
- 改装：三选一后点格子放下，或点已有同名牌升星
- 失败可点「续命」（MVP 先直接生效，未接微信广告）
